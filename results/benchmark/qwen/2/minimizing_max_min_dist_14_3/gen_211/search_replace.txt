The key insight is to improve the perturbation strategy by making it more sophisticated and adaptive. The current implementation uses simple random perturbations with fixed magnitudes, but we can enhance this by:

1. Using more intelligent perturbation directions based on local geometric analysis
2. Implementing a hybrid approach that considers both attractive/repulsive forces and curvature
3. Adding a mechanism to detect when points are in "bad" configurations (too clustered or too spread out) and adjust accordingly

This should improve the optimization dynamics and help escape local optima more effectively.
