The current implementation uses a single starting point with Fibonacci sphere initialization. To improve exploration of the solution space and avoid local optima, I'll implement a multi-start strategy that runs the optimization from multiple different initial configurations and retains the best result. This approach leverages the fact that the Fibonacci sphere already provides a good starting configuration, but running optimization from multiple diverse seeds allows us to explore different basins of attraction.

The key changes include:
1. Adding a multi-start wrapper that tries multiple initializations
2. Using different initialization methods (Fibonacci and icosahedral)
3. Adding random seeds to ensure proper diversity
4. Implementing early stopping when improvement plateaus

def min_max_dist_dim3_14() -> np.ndarray:
    """
    Creates 14 points in 3 dimensions in order to maximize the ratio of minimum to maximum distance.

    Returns
        points: np.ndarray of shape (14,3) containing the (x,y,z) coordinates of the 14 points.
    """
    np.random.seed(42)

    # Multi-start optimization with different initial configurations
    best_points = None
    best_ratio = 0.0

    # Different initialization strategies with different seeds
    initializations = [
        ("fibonacci", 42),
        ("fibonacci", 123),
        ("fibonacci", 456),
        ("icosahedral", 789),
        ("icosahedral", 999)
    ]

    for init_type, seed in initializations:
        np.random.seed(seed)

        if init_type == "fibonacci":
            points = PointInitializer.fibonacci_sphere(14)
        else:  # icosahedral
            points = PointInitializer.icosahedral_initialization(14)

        # Optimize using advanced spherical Voronoi-based approach
        optimizer = AdaptiveSimulatedAnnealing(max_time=360)
        optimized_points, optimized_ratio = optimizer.optimize(points)

        if optimized_ratio > best_ratio:
            best_ratio = optimized_ratio
            best_points = optimized_points.copy()

    return best_points
