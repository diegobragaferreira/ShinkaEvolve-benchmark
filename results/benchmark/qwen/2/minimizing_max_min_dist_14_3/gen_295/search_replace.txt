This edit introduces two key improvements to enhance the optimization process:
1. Adds proper spherical constraint handling by projecting points back to unit sphere after perturbations
2. Implements a more sophisticated perturbation strategy that considers point distances and uses tangent plane projections for better spherical geometry preservation

These changes address the fundamental issue in the current implementation where points can drift away from the unit sphere constraint during optimization, which negatively impacts the distance calculations and overall optimization quality.

    def project_to_unit_sphere(self, points: np.ndarray) -> np.ndarray:
        """Project points onto unit sphere to maintain spherical constraint"""
        norms = np.linalg.norm(points, axis=1, keepdims=True)
        # Avoid division by zero
        safe_norms = np.where(norms == 0, 1.0, norms)
        return points / safe_norms

    def tangent_plane_perturbation(self, point: np.ndarray, delta: float) -> np.ndarray:
        """Generate perturbation on tangent plane to sphere at given point"""
        # Generate random perturbation in 3D space
        perturbation = np.random.normal(0, delta, 3)

        # Project to tangent plane: remove component parallel to radius vector
        projection_factor = np.dot(perturbation, point)
        tangent_perturbation = perturbation - projection_factor * point

        return tangent_perturbation
