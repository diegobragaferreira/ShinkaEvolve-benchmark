<DESCRIPTION>
The current implementation uses a fixed perturbation scaling factor in the adaptive simulated annealing. This change introduces a more sophisticated adaptive perturbation scaling that considers the current configuration's distance distribution and convergence behavior. The new approach dynamically adjusts perturbation magnitudes based on:
1. Current minimum distance threshold (smaller distances get larger perturbations)
2. Distance variance (high variance gets more exploration)
3. Recent improvement trends (no improvement leads to larger perturbations)
4. Convergence indicators (slower cooling when approaching optimal solutions)

This should help escape local optima more effectively while maintaining precision during convergence.
