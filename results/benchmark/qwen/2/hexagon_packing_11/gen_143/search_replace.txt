<DESCRIPTION>
The key insight is to implement an adaptive margin calculation that computes the tightest possible bounding box for the inner hexagons rather than using a fixed multiplier. This will reduce unnecessary padding around the configuration and allow us to achieve a smaller outer hexagon side length, thus improving our objective function value. The approach calculates the minimum enclosing circle or bounding rectangle of all inner hexagon vertices and scales the outer hexagon accordingly.

This change directly addresses the geometric precision requirement mentioned in the recommendations and should help beat the current benchmark of 1/3.930092 ≈ 0.2544 by allowing tighter packing.

    def _estimate_initial_outer_side(self, initial_config: np.ndarray) -> float:
        """Estimate outer hexagon side length from initial configuration using adaptive margin"""
        # Calculate the tightest bounding box that contains all hexagons
        all_vertices = []

        # Get vertices for all inner hexagons
        for i in range(len(initial_config)):
            center_x, center_y, rotation = initial_config[i]
            vertices = HexagonUtils.hexagon_from_params(self.unit_hex_vertices, center_x, center_y, rotation)
            all_vertices.extend(vertices)

        if not all_vertices:
            return 2.0  # Default fallback

        # Convert to numpy array for easy computation
        vertices_array = np.array(all_vertices)

        # Compute bounding box
        min_x, max_x = np.min(vertices_array[:, 0]), np.max(vertices_array[:, 0])
        min_y, max_y = np.min(vertices_array[:, 1]), np.max(vertices_array[:, 1])

        # Compute width and height of bounding box
        width = max_x - min_x
        height = max_y - min_y

        # For a regular hexagon, we need to ensure our outer hexagon can contain all vertices
        # The side length of outer hexagon should accommodate the maximum dimension plus some margin
        # Using 1.1 factor as margin to ensure proper containment without excessive padding
        margin_factor = 1.1

        # For hexagons, we should consider that the hexagon circumscribes a circle
        # But since we're dealing with outer hexagon containment, we'll take max dimension
        max_dimension = max(width, height)

        # Return the side length needed to contain everything with margin
        return max_dimension * margin_factor
