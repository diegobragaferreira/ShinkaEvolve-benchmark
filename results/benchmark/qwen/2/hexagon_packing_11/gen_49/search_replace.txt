<DESCRIPTION>
The key insight is to implement adaptive outer hexagon sizing that calculates the tightest possible bounding box for the inner hexagons rather than using a conservative margin. This directly addresses the core optimization problem by allowing for more precise control over the outer hexagon size, which should help beat the current benchmark of 1/3.930092 ≈ 0.2544. Instead of adding a fixed margin, we'll compute the actual minimum bounding radius needed to contain all inner hexagon vertices, which leads to tighter packing and better inverse side length values.
