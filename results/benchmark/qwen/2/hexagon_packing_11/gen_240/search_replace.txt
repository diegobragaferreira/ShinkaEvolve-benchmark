<DESCRIPTION>
I'll implement an adaptive mutation strategy for the differential evolution algorithm to improve convergence and exploration. This approach dynamically adjusts the mutation parameters based on the optimization progress, which should help escape local optima and find better solutions for the hexagon packing problem.

The key insight is that in the early stages of optimization, we want more exploration with higher mutation rates, but as we approach convergence, we want more exploitation with lower mutation rates. This adaptive approach should help improve the overall performance compared to the fixed mutation parameters currently used.

    def _run_global_optimization(self, initial_config: np.ndarray) -> Tuple[np.ndarray, float, float]:
        """Run global differential evolution optimization with adaptive mutation"""
        # Prepare bounds and initial guess
        bounds = self._get_initial_bounds(initial_config)

        # Initial guess
        initial_params = self._initialize_parameters(initial_config)
        estimated_side = self._estimate_initial_outer_side(initial_config)
        initial_params.append(estimated_side)

        # Adaptive mutation parameters
        def adaptive_mutation(iteration, max_iter):
            """Adaptive mutation rate that decreases over time"""
            # Start with higher mutation for exploration
            # Gradually decrease to focus on exploitation
            start_mutation = 0.9
            end_mutation = 0.3
            return start_mutation - (start_mutation - end_mutation) * (iteration / max_iter)

        def adaptive_recombination(iteration, max_iter):
            """Adaptive recombination rate"""
            # Start with higher recombination for more diversity
            # Decrease to increase convergence speed
            start_recomb = 0.9
            end_recomb = 0.3
            return start_recomb - (start_recomb - end_recomb) * (iteration / max_iter)

        # Run optimization with adaptive parameters for better exploration/exploitation balance
        try:
            # Store intermediate results for adaptive behavior
            history = []

                # This will be called during optimization
                return self._objective_function(params)

                adaptive_objective,
                bounds,

                seed=42,
                maxiter=self.max_iterations,

                atol=1e-7,
                rtol=1e-7,

            opt_params = result.x
