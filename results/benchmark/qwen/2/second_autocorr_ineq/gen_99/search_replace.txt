The current implementation uses a simple Gaussian distribution for peak positioning which may not be optimal for maximizing C2. I'll implement a multi-scale Gaussian peak positioning strategy that uses logarithmic spacing to distribute peaks across different scales in the domain, which should help avoid clustering and create more diverse autoconvolution profiles that can yield higher C2 values.

This approach:
1. Uses logarithmic distribution of peak locations to ensure even spread across scales
2. Maintains the adaptive Gaussian structure but with better spatial distribution
3. Preserves the core optimization strategy while improving peak placement
4. Should help avoid the explosive autoconvolution norms that were problematic in previous attempts

    Construct a step function with adaptive Gaussian-based peak placement.

    # Generate positions using Gaussian distribution around center
    # This creates a bell-curve shaped distribution of peak heights
    positions = np.random.normal(0, 0.15, n_steps)
    # Clip to [-0.25, 0.25] to stay within domain
    positions = np.clip(positions, -0.25, 0.25)

    # Sort positions for proper step function construction
    positions = np.sort(positions)

    # Peaks closer to center get higher amplitude
    amplitudes = np.exp(-20 * positions**2)

    initial_noise_level = 0.1
    amplitudes += np.random.normal(0, initial_noise_level, n_steps)

    amplitudes = np.maximum(amplitudes, 0)

    # We do a quick check first
