This modification introduces adaptive peak shaping with controlled noise injection to improve the autoconvolution properties. Instead of using generic exponential random initialization, we implement a structured approach that builds upon known good patterns with adaptive noise injection. This helps in achieving better balance between maximizing ||g||₂² while keeping ||g||∞ under control, which directly improves the C₂ ratio. The noise level is dynamically adjusted based on current performance metrics to avoid getting stuck in poor local optima.

    population_size = 50
    generations = 200
    max_time_seconds = 85  # Leave room for finalization

    start_time = time.time()

    # Initialize population with structured approach inspired by successful patterns
    def create_structured_individual():
        # Create a base shape that tends to work well (e.g., Gaussian-like)
        length = np.random.randint(100, 1000)
        # Generate base with decreasing amplitudes to create smoother autoconvolutions
        base_shape = np.exp(-np.linspace(-2, 2, length)**2 / 2)
        # Add some controlled randomness to avoid local optima trapping
        noise_factor = 0.1
        noise = np.random.normal(0, noise_factor * np.mean(base_shape) if np.mean(base_shape) > 0 else 0.01, length)
        individual = np.clip(base_shape + noise, 0, 10.0)
        return individual.tolist()
