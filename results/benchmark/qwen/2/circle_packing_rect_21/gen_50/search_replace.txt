<DESCRIPTION>
Adding spatial indexing (KDTree) to accelerate overlap detection during constraint checking. This will significantly improve performance by reducing the O(n²) complexity of pairwise overlap checks to near-linear complexity, especially important given that we're checking 21 circles against each other multiple times during optimization.

The key insight is that the current implementation uses nested loops for overlap checking, which becomes increasingly expensive as the number of circles grows. By implementing spatial indexing, we can dramatically reduce the number of distance calculations needed for each circle's overlap checks.

We'll add the spatial indexing directly to the constraint validation functions rather than changing the overall structure too much.

        x_offset = 0.1  # Margin from left
