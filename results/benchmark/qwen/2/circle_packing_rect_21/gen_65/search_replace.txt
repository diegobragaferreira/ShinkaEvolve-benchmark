The current program uses a fixed hexagonal grid initialization that doesn't scale well for different circle counts or rectangle aspect ratios. This change implements an adaptive grid initialization that calculates optimal spacing based on the target number of circles and rectangle dimensions, creating a better starting configuration that's more likely to lead to higher-quality solutions.

The key insight is that for 21 circles in a unit square, we want to distribute them efficiently to maximize the total radius sum. An adaptive grid approach calculates the appropriate spacing dynamically rather than using arbitrary heuristics.

    def generate_initial_guess():
        # Calculate optimal grid spacing based on circle count and rectangle size
        # For 21 circles in a 1x1 rectangle, we want efficient packing
        # Use a more sophisticated approach: calculate area per circle and derive spacing

        # Target area per circle (total area is 1, so area per circle = 1/n)
        area_per_circle = rect_width * rect_height / n
        # Approximate radius from area (A = πr² => r = √(A/π))
        target_radius = np.sqrt(area_per_circle / np.pi)

        # Determine grid dimensions to place circles reasonably
        # Use sqrt of n to get roughly square grid
        grid_size = int(np.ceil(np.sqrt(n)))

        # Calculate spacing to fill rectangle efficiently
        # Leave some margin for circles to have room to grow
        spacing_x = rect_width / (grid_size + 1)
        spacing_y = rect_height / (grid_size + 1)

        # Ensure minimum spacing
        min_spacing = target_radius * 2.5  # Allow some buffer for growth
        spacing_x = max(spacing_x, min_spacing)
        spacing_y = max(spacing_y, min_spacing)

        # Create grid of positions
        circles = np.zeros((n, 3))
        idx = 0

        for i in range(grid_size):
            for j in range(grid_size):
                if idx >= n:
                    break
                # Position with offset for hexagonal-like arrangement
                x = spacing_x * (j + 1)
                y = spacing_y * (i + 1)
                # Add offset for odd rows to create better packing
                if i % 2 == 1:
                    x += spacing_x / 2

                # Ensure positions are valid
                x = max(target_radius, min(rect_width - target_radius, x))
                y = max(target_radius, min(rect_height - target_radius, y))

                # Initialize with calculated target radius
                r = target_radius * 0.8  # Slightly smaller to allow room for optimization
