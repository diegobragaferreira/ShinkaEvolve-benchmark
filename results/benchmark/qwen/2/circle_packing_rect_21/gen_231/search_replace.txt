However, we can improve performance by implementing a constraint-aware objective function that explicitly incorporates violation penalties into the fitness calculation. This approach helps guide optimization towards feasible solutions more effectively, rather than relying solely on post-hoc penalty application.

The key insight is to create a fitness function that includes both the objective (radius sum) and constraint violations in a way that prevents the optimizer from exploring infeasible regions. This will help avoid getting stuck in local minima where many circles overlap significantly.

    def calculate_fitness(self, circles: np.ndarray) -> Tuple[float, int]:
        """Calculate fitness with constraint-aware objective function."""
        # Quick boundary check first
        boundary_violations = 0
        for i in range(self.num_circles):
            x, y, r = circles[i]
            if not self.validator.is_valid_circle(x, y, r):
                boundary_violations += 1  # Count violations

        # If boundary violations, penalize heavily
        if boundary_violations > 0:
            # Large penalty to strongly discourage infeasible solutions
            base_fitness = -10000.0
            # Add penalty based on number of violations
            base_fitness -= 1000.0 * boundary_violations
            return base_fitness, boundary_violations

        total_radius = np.sum(circles[:, 2])

        # Check overlap violations
        overlap_violations = len(self.validator.find_overlapping_pairs(circles))

        # Constraint-aware fitness calculation
        # We penalize heavily for violations to encourage feasibility
        if overlap_violations > 0:
            # Use a weighted penalty system that considers severity of violations
            total_penalty = 0

            # Get all overlapping pairs and compute actual overlap amounts
            overlapping_pairs = self.validator.find_overlapping_pairs(circles)
            for i, j in overlapping_pairs:
                x1, y1, r1 = circles[i]
                x2, y2, r2 = circles[j]
                dx = x1 - x2
                dy = y1 - y2
                distance = np.sqrt(dx*dx + dy*dy)
                overlap = (r1 + r2) - distance
                # More severe penalties for deeper overlaps
                total_penalty += 10000.0 * overlap**2

            return total_radius - total_penalty, overlap_violations
        else:
            # No violations - return just the radius sum
            return total_radius, 0
