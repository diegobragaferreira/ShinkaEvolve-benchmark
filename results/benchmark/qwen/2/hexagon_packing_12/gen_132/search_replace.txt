<DESCRIPTION>
Implement Numba JIT compilation for geometric operations to significantly speed up the constraint validation and fitness computation. This addresses the computational bottleneck in the constraint checking functions which are called frequently during optimization. The key functions to JIT compile are `generate_hexagon_vertices`, `create_hexagon_polygon`, `check_containment`, `check_overlap`, and `calculate_overlap_area` in the GeometryHandler class, as well as the constraint violation computation in ConstraintChecker. This optimization should dramatically reduce evaluation time while maintaining numerical accuracy.

        return outer_hex.contains(hexagon) or outer_hex.touches(hexagon)

    def check_overlap(self, hex1: Polygon, hex2: Polygon) -> bool:
        """Check if two hexagons overlap."""
        return hex1.intersects(hex2) and not hex1.touches(hex2)

    def calculate_overlap_area(self, hex1: Polygon, hex2: Polygon) -> float:
        """Calculate the overlap area between two hexagons."""
        try:
            intersection = hex1.intersection(hex2)
            return intersection.area if not intersection.is_empty else 0.0
        except:
            return 0.0

    def compute_constraint_violations(self, hex_configs: List[HexagonConfig],
                                    outer_radius: float) -> Tuple[bool, float]:

        # Create outer hexagon (scaled appropriately)
