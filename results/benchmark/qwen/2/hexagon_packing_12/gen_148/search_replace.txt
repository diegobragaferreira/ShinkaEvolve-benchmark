I'll implement adaptive penalty weighting to improve the optimization performance. The idea is to dynamically adjust penalty weights based on constraint violation severity. This addresses the issue that containment violations are more fundamental than overlap violations and should be penalized more heavily. This change should help the optimizer focus more effectively on maintaining containment while still avoiding overlaps.

The key insight is to assign higher penalties (1500 for containment violations vs. 1000 for overlap violations) since containment is more critical to the problem formulation. This makes the optimization landscape smoother for convergence while still strongly discouraging constraint violations.

    outer_hex_vertices = hexagon_vertices(0, 0, 0, outer_radius)
    for i in range(n):
        vertices = hex_vertices_list[i]
        # Check containment penalty with higher weight

            if not point_in_polygon(point, outer_hex_vertices):
                dist = np.sqrt(vx*vx + vy*vy)
                # Higher penalty weight for containment violations
