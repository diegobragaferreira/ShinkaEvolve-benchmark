<DESCRIPTION>
Adding adaptive perturbation scaling to the initialization phase based on the current distance distribution. This enhancement dynamically adjusts the magnitude of random perturbations applied to points during initialization, using the inverse of the current minimum/maximum distance ratio as a scaling factor. When the configuration is already well-balanced (high ratio), smaller perturbations are used to preserve good solutions. When the configuration is poorly balanced (low ratio), larger perturbations allow for more dramatic improvements. This builds upon the existing symmetric grid initialization and aims to make the starting configurations more effective for optimization.
