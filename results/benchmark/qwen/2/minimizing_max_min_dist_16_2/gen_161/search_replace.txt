<DESCRIPTION>
This improvement enhances the multi-start optimization approach by implementing adaptive perturbation scaling based on the current distance distribution. The key insight is that during early optimization iterations when distances are poorly balanced, larger perturbations are beneficial for escaping local minima, but as the configuration approaches optimality, smaller perturbations prevent destabilizing good solutions. This approach combines the robustness of multiple starting strategies with intelligent perturbation sizing that adapts to the optimization landscape.

The main changes include:
1. Adding a function to compute current distance ratio for adaptive perturbation scaling
2. Modifying the grid initialization to use adaptive perturbation magnitudes
3. Implementing a more sophisticated multi-start strategy that selects perturbation sizes based on current performance
4. Adding a small amount of symmetry-breaking to avoid degenerate solutions

    def create_initial_grid():
        """Create initial 4x4 grid points"""
        grid_size = 4
        x_vals = np.linspace(0.05, 0.95, grid_size)
        y_vals = np.linspace(0.05, 0.95, grid_size)
        return np.array([[x, y] for x in x_vals for y in y_vals])

    def perturb_points(points, magnitude):
        """Add controlled random perturbations"""
        np.random.seed(42)  # For reproducibility
        noise = np.random.normal(0, magnitude, points.shape)
        perturbed = points + noise
        return np.clip(perturbed, 0, 1)

    def compute_current_ratio(points):
        """Compute current min/max distance ratio for adaptive scaling"""
        if len(points) < 2:
            return 0.0
        distances = pdist(points)
        if len(distances) == 0:
            return 0.0
        min_dist = np.min(distances)
        max_dist = np.max(distances)
        if max_dist == 0:
            return 0.0
        return min_dist / max_dist

    def adaptive_perturb_points(points, base_magnitude=0.02):
        """Add random perturbations with adaptive magnitude based on current configuration quality"""
        # Calculate current ratio to determine perturbation size
        current_ratio = compute_current_ratio(points)

        # Scale perturbation based on how well-balanced the distances currently are
        # If ratio is very low (bad configuration), use larger perturbations
        # If ratio is high (good configuration), use smaller perturbations
        if current_ratio < 0.1:
            # Very poor configuration - use larger perturbations for exploration
            magnitude = base_magnitude * 2.0
        elif current_ratio < 0.2:
            # Poor configuration - use medium perturbations
            magnitude = base_magnitude * 1.5
        else:
            # Reasonable configuration - use small perturbations for fine-tuning
            magnitude = base_magnitude * 0.5

        return perturb_points(points, magnitude)
