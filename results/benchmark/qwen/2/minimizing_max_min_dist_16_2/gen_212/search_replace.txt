I'll implement adaptive perturbation scaling based on the current distance distribution. This enhancement will dynamically adjust the magnitude of random perturbations during initialization depending on how well-balanced the current point distribution is. When distances are already relatively uniform, smaller perturbations are used to avoid disrupting good configurations. When distances are skewed, larger perturbations allow for more aggressive exploration of the solution space.

This approach builds on the existing multi-start strategy by making the initialization process smarter - instead of using fixed perturbation magnitudes, we adapt them based on the current state of the configuration.

    def create_initial_configurations():

        configs = []

        # Helper function to compute distance ratio for perturbation scaling
        def compute_distance_ratio(points):
            distances = pdist(points)
            if len(distances) == 0:
                return 0.0
            d_min = np.min(distances)
            d_max = np.max(distances)
            if d_max == 0:
                return 0.0
            return d_min / d_max

        # Configuration 1: Structured 4x4 grid with adaptive perturbations
        np.random.seed(42)
        grid_x = np.linspace(0.1, 0.9, 4)
