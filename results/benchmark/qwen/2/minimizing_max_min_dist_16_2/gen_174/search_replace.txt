<DESCRIPTION>
The key insight is to implement adaptive perturbation scaling in the grid initialization. Instead of using fixed perturbation magnitudes, we should dynamically adjust the perturbation based on the current distance distribution. When the configuration has a poor min/max ratio (indicating distances are skewed), we should use larger perturbations to explore more aggressively. When the configuration is already well-balanced, we should use smaller perturbations to fine-tune without disrupting good arrangements.

This builds on the existing multi-start approach but makes the perturbation strategy smarter by adapting to the current state of the optimization landscape.

        """Add controlled random perturbations"""

        noise = np.random.normal(0, magnitude, points.shape)

    def perturb_points_adaptive(points, current_ratio):
        """Add adaptive random perturbations based on current solution quality"""
        # Scale perturbation magnitude inversely with the current ratio
        # If ratio is low (bad solution), use larger perturbations
        # If ratio is high (good solution), use smaller perturbations
        base_magnitude = 0.05
        # The adjustment factor ensures we don't perturb too aggressively when solution is already good
        adjustment_factor = max(0.1, 1.0 - current_ratio * 2.0)  # Decrease perturbation as ratio increases
        magnitude = base_magnitude * adjustment_factor
        np.random.seed(42)  # For reproducibility
        noise = np.random.normal(0, magnitude, points.shape)
        perturbed = points + noise
        return np.clip(perturbed, 0, 1)
