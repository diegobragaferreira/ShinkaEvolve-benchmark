The current implementation uses a fixed jitter magnitude for initial point generation. This approach doesn't adapt to the specific characteristics of the optimization landscape. I'll implement adaptive perturbation scaling that adjusts the perturbation magnitude based on the current distance distribution during optimization. This will help avoid getting stuck in poor local optima and allow for more intelligent exploration of the solution space.

The key insight is to introduce adaptive perturbation that scales inversely with the current min/max distance ratio - larger perturbations when distances are poorly balanced, smaller ones when the configuration is already well-distributed. This builds upon the existing structured initialization but makes the perturbation process more intelligent.
