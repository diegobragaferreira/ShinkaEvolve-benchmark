<DESCRIPTION>
The main idea is to implement adaptive perturbation scaling in the grid initialization based on distance distribution. The current implementation uses fixed perturbation standards, but we can make it smarter by analyzing the ratio of minimum to maximum distances at the start of optimization and scaling perturbations inversely with this ratio. This way, when the configuration is already well-balanced (high ratio), we use smaller perturbations to avoid destabilizing good configurations, and when the configuration is highly skewed (low ratio), we use larger perturbations to encourage better exploration of the solution space.

This builds on the existing structured initialization approach but adds intelligence to the perturbation process, which should improve convergence speed and solution quality by avoiding unnecessary large jumps that might destabilize good configurations.
</DESCRIPTION>
