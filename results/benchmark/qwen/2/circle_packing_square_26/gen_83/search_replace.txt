<DESCRIPTION>
The current implementation uses a fixed mutation probability of 0.15 throughout all generations. This can lead to either premature convergence (if too low) or excessive exploration (if too high). I'll implement an adaptive mutation rate that decreases over time to allow for initial exploration followed by focused exploitation, which should help the algorithm converge to better solutions more effectively.

This change involves:
1. Adding a function to compute adaptive mutation rate that decreases exponentially
2. Modifying the evolution loop to use this adaptive rate
3. Updating the mutation operator registration to use dynamic rates
</DESCRIPTION>
