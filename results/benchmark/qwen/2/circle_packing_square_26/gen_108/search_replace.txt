<DESCRIPTION>
The current implementation uses a fixed mutation rate of 0.1 throughout all generations. This can lead to premature convergence early on when the population is diverse, or insufficient exploration later when the population becomes more homogeneous. I'll implement an adaptive mutation rate that decreases over generations to balance exploration and exploitation more effectively. This follows successful patterns seen in previous generations where mutation rate decay improved performance.
</DESCRIPTION>

def mutate(individual: np.ndarray, generation: int) -> np.ndarray:
    """Apply mutation to an individual with adaptive rate"""
    mutated = individual.copy()
    n = len(mutated)

    # Calculate adaptive mutation rate
    mutation_rate = INITIAL_MUTATION_RATE - (INITIAL_MUTATION_RATE - FINAL_MUTATION_RATE) * (generation / GENERATIONS)

    for i in range(n):
        if random.random() < mutation_rate:
            # Mutate either position or radius
            if random.random() < 0.5:
                # Mutate position
                mutated[i, 0] += (random.random() - 0.5) * 0.1
                mutated[i, 1] += (random.random() - 0.5) * 0.1

                # Keep within bounds
                mutated[i, 0] = np.clip(mutated[i, 0], 0.01, 0.99)
                mutated[i, 1] = np.clip(mutated[i, 1], 0.01, 0.99)
            else:
                # Mutate radius
                mutated[i, 2] += (random.random() - 0.5) * 0.05

                # Ensure positive radius
                mutated[i, 2] = max(0.001, mutated[i, 2])

    # Repair any constraint violations
    repaired = repair_constraints(mutated)
    return repaired
