<DESCRIPTION>
This enhancement introduces an adaptive local search mechanism that intelligently adjusts its refinement intensity based on the overlap severity of the current solution. The approach classifies solutions into three categories (low, medium, high overlap) and applies corresponding optimization strategies. This builds upon the existing local_optimize function but makes it much more sophisticated by tailoring the refinement approach to the specific problem state rather than using a uniform strategy.

The key improvements include:
1. Dynamically assessing overlap severity to determine optimization approach
2. Applying different refinement strategies (light, moderate, intensive) based on overlap levels
3. Using physics-based repulsion for high overlap cases
4. Incorporating greedy radius expansion for low overlap scenarios
5. Better handling of edge cases through intelligent strategy switching

This is expected to significantly improve the final solution quality by applying the right amount of optimization effort at the right time.

def local_optimize(circles: np.ndarray, max_iterations: int = 20) -> np.ndarray:
    """Apply adaptive local optimization to improve a solution by making smart adjustments."""
    optimized = circles.copy()
    n = len(optimized)

    # Calculate overlap severity for adaptive strategy
    def calculate_overlap_severity():
        overlaps = 0
        for i in range(n):
            for j in range(i+1, n):
                x1, y1, r1 = optimized[i]
                x2, y2, r2 = optimized[j]
                dist = np.sqrt((x1 - x2)**2 + (y1 - y2)**2)
                if dist < r1 + r2:
                    overlaps += 1
        return overlaps

    overlap_severity = calculate_overlap_severity()

    # Apply different optimization strategies based on overlap severity
    if overlap_severity < 5:  # Low overlap - light refinement
        # Try greedy radius expansion for unoccupied space
        for _ in range(max_iterations // 2):
            improved = False
            for i in range(n):
                x, y, r = optimized[i]
                # Calculate maximum possible radius
                max_radius = min(x, 1-x, y, 1-y)
                if max_radius <= r:
                    continue

                new_r = min(r + 0.005, max_radius)

                # Check if we can actually increase radius
                valid = True
                for j in range(n):
                    if i != j:
                        x2, y2, r2 = optimized[j]
                        dist = np.sqrt((x - x2)**2 + (y - y2)**2)
                        if dist < new_r + r2:
                            valid = False
                            break

                if valid and new_r > r:
                    optimized[i, 2] = new_r
                    improved = True

            if not improved:
                break
