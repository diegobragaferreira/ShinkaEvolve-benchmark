<DESCRIPTION>
I'll implement a constraint-aware crossover that takes into account the overlap probability between corresponding circles in parent solutions. This will help reduce the number of invalid offspring generated during recombination by weighting crossover probabilities based on how likely circles are to overlap.

The key insight is that when two circles are far apart (low overlap probability), we can safely exchange their genes with higher probability. When they're close together (high overlap probability), we should be more conservative about crossing them.

def crossover(parent1: np.ndarray, parent2: np.ndarray) -> np.ndarray:
    """Constraint-aware crossover that weights recombination probability based on overlap risk"""
    child = parent1.copy()

    # For each circle, assess overlap risk with corresponding circle in parent2
    crossover_probs = np.ones(parent1.shape[0])  # Default 100% crossover probability

    # Calculate overlap risk for each pair of circles
    for i in range(len(parent1)):
        x1, y1, r1 = parent1[i]
        x2, y2, r2 = parent2[i]

        # Calculate distance between centers
        distance = np.sqrt((x1 - x2)**2 + (y1 - y2)**2)
        min_distance = r1 + r2

        # Risk increases as circles get closer to minimum distance
        if distance < min_distance * 1.5:  # Only consider risk when circles are relatively close
            # Risk is inversely proportional to how close they are
            risk = max(0, 1.0 - (distance / min_distance))
            # Reduce crossover probability for high-risk pairs
            crossover_probs[i] = max(0.3, 0.8 - risk * 0.5)

    # Apply crossover with risk-adjusted probabilities
    mask = np.random.rand(*parent1.shape) > (1 - crossover_probs[:, np.newaxis])
    child[mask] = parent2[mask]

    return child
