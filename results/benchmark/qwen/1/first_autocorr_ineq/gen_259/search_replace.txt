The proposed enhancement focuses on improving the local search mechanism by integrating a more sophisticated gradient-based approach with the existing LP-based method. The core idea is to add a gradient descent component that refines the solution more effectively by taking advantage of the continuous nature of the parameter space, specifically targeting the reduction of convolution peaks.

This improvement will:
1. Enhance the `get_good_direction_to_move_into` function to include gradient descent steps
2. Apply the gradient descent in a way that complements the existing LP-based optimization
3. Maintain computational efficiency while improving solution quality

The motivation comes from the fact that while the linear programming approach provides a good direction, it might miss finer adjustments possible through gradient-based optimization, especially when dealing with smooth variations in the sequence heights.

def get_good_direction_to_move_into(
    sequence: list[float],
) -> list[float] | None:
    """Returns the direction to move into the sequence with enhanced local search."""
    n = len(sequence)
    sum_sequence = np.sum(sequence)

    if sum_sequence < 0.01:
        return None

    # Normalize the sequence for processing
    normalized_sequence = [x * np.sqrt(2 * n) / sum_sequence for x in sequence]
    rhs = np.max(np.convolve(normalized_sequence, normalized_sequence))
    g_fun = solve_convolution_lp(normalized_sequence, rhs)

    if g_fun is None:
        # Fallback to a simple gradient-based approach if LP fails
        return gradient_improve_sequence(sequence, step_size=0.05)

    sum_sequence = np.sum(g_fun)
    normalized_g_fun = [x * np.sqrt(2 * n) / sum_sequence for x in g_fun]
    t = 0.01
    new_sequence = [

    ]
