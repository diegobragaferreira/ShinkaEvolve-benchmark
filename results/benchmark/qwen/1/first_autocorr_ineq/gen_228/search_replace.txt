<DESCRIPTION>
The current implementation uses FFT-based convolution for all sequence sizes, but this is inefficient for very short sequences where the O(n^2) direct method might be faster. I'll modify the evaluator to use direct convolution for small sequences and FFT only for larger ones. This should provide a performance boost without changing the core logic.
