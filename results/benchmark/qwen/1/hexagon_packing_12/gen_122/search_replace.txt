<DESCRIPTION>
The key insight is to implement spatial acceleration using cKDTree to dramatically improve the overlap detection performance. Currently, the code performs O(n²) pairwise overlap checking for all 12 hexagons, which becomes increasingly expensive. By using a cKDTree to index hexagon centers and only checking nearby candidates for detailed overlap testing, we can significantly reduce the number of expensive Shapely intersection operations. This addresses the performance bottleneck identified in the problem statement and follows the successful pattern from previous generations.

The implementation involves:
1. Adding scipy.spatial.cKDTree import
2. Modifying the overlap checking logic to use spatial indexing
3. Only performing expensive intersection tests on potentially overlapping pairs
4. Maintaining all existing functionality while improving performance

def fast_check_overlap_pair_fast(hex1, hex2):
    """Fast preliminary overlap check using bounding circles before detailed Shapely check."""
    # Calculate centers and radii
    # For unit hexagons, the circumradius is 1 and inradius is sqrt(3)/2
    hex1_center = np.mean([list(p) for p in hex1.exterior.coords[:-1]], axis=0)
    hex2_center = np.mean([list(p) for p in hex2.exterior.coords[:-1]], axis=0)

    # Distance between centers
    dist = np.linalg.norm(hex1_center - hex2_center)

    # If distance is greater than sum of radii (2), they don't overlap
    if dist > 2.0:
        return False

    # Perform detailed overlap check only if close enough
    return check_overlap(hex1, hex2)

def efficient_parallel_overlap_check(hexagons, tree, max_distance=2.0):
    """Efficient overlap checking using spatial indexing."""
    overlaps = []
    n_hexagons = len(hexagons)

    # Query nearby hexagons using cKDTree
    for i in range(n_hexagons):
        # Find neighbors within max_distance
        nearby_indices = tree.query_ball_point(list(hexagons[i].exterior.centroid.coords)[0], max_distance)

        # Check overlaps only with nearby hexagons
        for j in nearby_indices:
            if i < j:  # Only check each pair once
                if fast_check_overlap_pair_fast(hexagons[i], hexagons[j]):
                    overlaps.append((i, j))
