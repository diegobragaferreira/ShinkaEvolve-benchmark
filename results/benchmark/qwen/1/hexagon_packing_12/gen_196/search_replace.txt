<DESCRIPTION>
The current implementation uses cKDTree for spatial acceleration but doesn't leverage more advanced spatial data structures like BVH (Bounding Volume Hierarchy) for hexagon overlap detection. BVH is particularly effective for polygon intersection queries and can significantly improve performance for the hexagon packing problem. I'll implement a BVH-based approach to replace the current overlap detection system.

This change addresses the key bottleneck in hexagon overlap checking by:
1. Replacing cKDTree-based neighbor finding with BVH for better spatial queries
2. Implementing proper AABB (Axis-Aligned Bounding Box) calculations for hexagons
3. Adding BVH traversal logic specifically tuned for hexagon-hexagon overlap detection
4. Maintaining compatibility with existing constraint checking infrastructure
