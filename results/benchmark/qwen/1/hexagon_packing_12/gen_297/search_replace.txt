<DESCRIPTION>
Adding Numba JIT compilation to the most computationally intensive functions will significantly improve performance. The key functions that benefit most from JIT compilation are:
1. `_generate_vertices` in the Hexagon class - called frequently for all hexagons
2. `fast_overlap_check` in HexagonPacker - performs many geometric calculations
3. The overlap checking logic that iterates through pairs
4. The main `evaluate` function in OptimizationEngine

This follows the proven approach from previous generations that achieved high scores, specifically leveraging numba's @njit decorator to compile Python loops to machine code for dramatic speedups in geometric computations.
</DESCRIPTION>
