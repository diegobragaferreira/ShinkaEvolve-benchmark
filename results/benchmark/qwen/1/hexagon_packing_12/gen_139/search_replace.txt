<DESCRIPTION>
Adding spatial acceleration using cKDTree to significantly improve overlap detection performance. This addresses the main bottleneck in the current implementation where all pairwise overlap checks are performed in O(n²) time. The cKDTree will allow us to quickly identify only nearby hexagons that need detailed overlap testing, reducing the complexity to O(n log n) average case while maintaining the same optimization framework.

The key insight is that most hexagons are far apart and won't overlap, so we should use spatial indexing to avoid unnecessary expensive Shapely intersection tests. This follows the pattern established in previous generations that achieved the SOTA benchmark ratio of 0.2537.
