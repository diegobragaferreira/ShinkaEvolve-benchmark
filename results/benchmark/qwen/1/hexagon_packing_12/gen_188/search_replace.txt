<DESCRIPTION>
Adding Numba JIT compilation to critical geometric functions will significantly speed up the constraint validation process, especially the overlap checking and containment validation. This is crucial given the computational intensity of evaluating 12 hexagons with pairwise overlap checks and vertex containment checks. The key functions to JIT compile are `create_hexagon_vertices`, `check_containment_all_vertices`, and `check_overlap_pair`.

Looking at the current code, I can see that there's already some numba usage in the prior implementations (like in the HexagonGeometry class). However, the current implementation doesn't leverage numba for its geometric computations which are the most time-consuming parts. By applying `@njit` decorators to the core geometric functions, we can achieve substantial performance improvements that will allow for more thorough exploration of the solution space within the 180-second limit.
</DESCRIPTION>

def create_hexagon_vertices(center, side_length, rotation_degrees):
    """Create vertices of a regular hexagon."""
    angle_rad = np.radians(rotation_degrees)
    angle_step = 2 * np.pi / 6
    vertices = []
    for i in range(6):
        angle = angle_step * i + angle_rad
        x = center[0] + side_length * np.cos(angle)
        y = center[1] + side_length * np.sin(angle)
        vertices.append((x, y))
    return np.array(vertices)

def check_containment_all_vertices(hex_vertices, outer_hex_center, outer_hex_side_length):
    """Check if all vertices of a hexagon are inside the outer hexagon."""
    outer_vertices = create_hexagon_vertices(outer_hex_center, outer_hex_side_length, 0)
    outer_polygon = Polygon(outer_vertices)

    for vertex in hex_vertices:
        point = Point(vertex)
        if not outer_polygon.contains(point):
            return False
    return True
