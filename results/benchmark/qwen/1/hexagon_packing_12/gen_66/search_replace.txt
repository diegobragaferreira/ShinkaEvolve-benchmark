<DESCRIPTION>
The main improvement is to implement parallelized geometric validation using joblib to accelerate overlap and containment checks. The current implementation uses sequential loops for checking all pairwise overlaps (66 checks) and vertex containment validations, which becomes a major bottleneck. By leveraging `joblib.Parallel` with `joblib.delayed`, we can distribute these expensive geometric operations across multiple CPU cores, significantly reducing evaluation time during differential evolution iterations. This allows for more evaluations within the 180-second time budget and potentially better convergence to higher-quality solutions.

def evaluate_configuration(inner_hex_data, outer_hex_center=(0,0)):
    """Evaluate a configuration for validity and return inverse side length."""
    if len(inner_hex_data) != 12:
        return 1e-10

    # Create all hexagon polygons
    hex_polygons = []
    for i in range(len(inner_hex_data)):
        cx, cy, angle = inner_hex_data[i]
        vertices = create_hexagon_vertices((cx, cy), 1.0, angle)
        hex_polygons.append(Polygon(vertices))

    # Check containment: all hexagon vertices must be within outer hexagon
    outer_side_length = compute_outer_hex_side_from_config(inner_hex_data, outer_hex_center)
    outer_vertices = create_hexagon_vertices(outer_hex_center, outer_side_length, 0)
    outer_polygon = Polygon(outer_vertices)

    # Check containment for all vertices in parallel
    def check_vertex_containment(hex_idx):
        vertices = hex_polygons[hex_idx].exterior.coords[:-1]  # Exclude last point (duplicate of first)
        for vertex in vertices:
            point = Point(vertex)
            if not outer_polygon.contains(point):
                return False
        return True

    # Parallelize vertex containment checks
    containment_results = Parallel(n_jobs=-1)(delayed(check_vertex_containment)(i) for i in range(len(inner_hex_data)))

    if not all(containment_results):
        return 1e-10

    # Check overlaps between all pairs of hexagons in parallel
    def check_overlap_pair(i, j):
        return hex_polygons[i].intersects(hex_polygons[j])

    # Generate all unique pairs
    pairs = [(i, j) for i in range(len(inner_hex_data)) for j in range(i+1, len(inner_hex_data))]

    # Parallelize overlap checks
    overlap_results = Parallel(n_jobs=-1)(delayed(check_overlap_pair)(i, j) for i, j in pairs)

    if any(overlap_results):
        return 1e-10

    # If we reach here, the configuration is valid
    return 1.0 / outer_side_length
