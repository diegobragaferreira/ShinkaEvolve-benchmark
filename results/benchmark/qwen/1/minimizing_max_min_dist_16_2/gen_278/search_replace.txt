<DESCRIPTION>
This change introduces a simulated annealing fallback mechanism to improve the optimization process. The idea is to add a secondary optimization method that can escape local optima when the primary evolutionary algorithm gets stuck. This is particularly important for complex optimization landscapes like the point dispersion problem where multiple local maxima exist. The simulated annealing will be triggered when the evolutionary search shows signs of stagnation, providing a more robust path to finding better solutions.

The implementation adds a new `_simulated_annealing` function that uses a temperature-based acceptance criterion to allow occasional uphill moves, helping escape local maxima. This is integrated into the main optimization flow after the evolutionary search but before returning the final result.
</DESCRIPTION>

def _simulated_annealing(points: np.ndarray, max_iter: int = 1000) -> np.ndarray:
    """Perform simulated annealing to escape local optima."""
    def objective(x_flat):
        points_candidate = x_flat.reshape(-1, 2)
        return -_compute_distance_ratio(points_candidate)

    # Flatten points for optimization
    current_solution = points.flatten().copy()
    current_energy = objective(current_solution)

    # Initialize temperature and cooling schedule
    temperature = 0.1
    cooling_rate = 0.995
    min_temperature = 1e-8

    # Store best solution found
    best_solution = current_solution.copy()
    best_energy = current_energy

    for iteration in range(max_iter):
        # Generate neighbor solution by adding small random perturbation
        neighbor = current_solution.copy()
        # Randomly select points to perturb
        n_points = len(points)
        n_perturb = max(1, n_points // 10)  # Perturb about 10% of points
        indices = np.random.choice(n_points, n_perturb, replace=False)

        for idx in indices:
            # Add Gaussian noise scaled by temperature
            noise = np.random.normal(0, 0.005 * temperature, 2)
            # Apply noise to the corresponding point
            neighbor[idx*2:(idx+1)*2] += noise
            # Ensure bounds
            neighbor[idx*2:(idx+1)*2] = np.clip(neighbor[idx*2:(idx+1)*2], 0, 1)

        # Evaluate neighbor
        neighbor_energy = objective(neighbor)

        # Accept or reject the neighbor based on Metropolis criterion
        if neighbor_energy < current_energy:
            # Always accept better solutions
            current_solution = neighbor.copy()
            current_energy = neighbor_energy
        else:
            # Accept worse solutions with probability based on temperature
            delta_energy = neighbor_energy - current_energy
            acceptance_probability = np.exp(-delta_energy / temperature)
            if np.random.random() < acceptance_probability:
                current_solution = neighbor.copy()
                current_energy = neighbor_energy

        # Update best solution if needed
        if current_energy < best_energy:
            best_solution = current_solution.copy()
            best_energy = current_energy

        # Cool down temperature
        temperature *= cooling_rate

        # Stop if temperature gets too low
        if temperature < min_temperature:
            break

    # Return best solution found
    best_points = best_solution.reshape(-1, 2)
    return np.clip(best_points, 0, 1)
