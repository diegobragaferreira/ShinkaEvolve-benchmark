<DESCRIPTION>
This enhancement improves the multi-start optimization approach by implementing several key improvements:

1. Increased number of optimization starts from 5 to 15 to better explore the search space
2. Added adaptive perturbation scaling that decreases with each start to fine-tune convergence
3. Implemented a more sophisticated refinement strategy with multiple optimization stages
4. Added better error handling and fallback mechanisms
5. Improved the objective function to use a more stable distance calculation

These changes should help escape local optima more effectively and converge toward better solutions with higher min/max ratios.
