<DESCRIPTION>
The current implementation uses purely random point placement which is unlikely to yield good results for the distance maximization problem. I'll implement a better initialization strategy using a Fibonacci spiral projection onto a sphere, which provides more uniform point distribution. This heuristic approach should give us a much better starting configuration that's closer to optimal than random placement.

The Fibonacci spiral approach works by:
1. Distributing points evenly along the latitude of a sphere using Fibonacci-like spacing
2. Projecting these points to the surface of the unit sphere
3. This gives a good initial configuration that's more likely to have larger minimum distances

This change alone should significantly improve the baseline performance before any optimization is applied.

import numpy as np


def min_max_dist_dim3_14() -> np.ndarray:
    """
    Creates 14 points in 3 dimensions in order to maximize the ratio of minimum to maximum distance.

    Returns
        points: np.ndarray of shape (14,3) containing the (x,y) coordinates of the 14 points.

    """
    n = 14

    # Use Fibonacci spiral initialization on sphere for better point distribution
    points = []
    phi = (1 + np.sqrt(5)) / 2  # golden ratio

    for i in range(n):
        # Distribute points along longitude (azimuthal angle)
        theta = 2 * np.pi * i / phi

        # Distribute points along latitude (polar angle) using Fibonacci-like spacing
        # This avoids clustering at poles
        y = 1.0 - (2.0 * i) / (n - 1)
        radius = np.sqrt(1 - y*y)

        x = radius * np.cos(theta)
        z = radius * np.sin(theta)

        points.append([x, y, z])

    points = np.array(points)

    # Normalize to unit sphere (this ensures all points are equidistant from center)
    # But we'll scale appropriately for our optimization later
    return points
