<DESCRIPTION>
Adding adaptive constraint tightening to improve convergence stability. The idea is to start with a looser constraint (allowing points to be within a larger radius) and gradually tighten it towards the final unit sphere constraint as optimization progresses. This allows more flexible exploration in early iterations while enforcing stricter feasibility conditions later, which should help escape poor local minima and converge to better solutions.

This approach follows successful patterns from high-performing programs that balance exploration and exploitation by dynamically adjusting constraints during the optimization process.

    def setup_adaptive_constraint(self, iteration: int = 0, max_iterations: int = 1000) -> dict:
        """Setup adaptive constraint with dynamic radius based on iteration."""
        # Start with a larger radius to allow more exploration
        initial_radius = 1.5
        final_radius = 1.0

        # Interpolate radius based on iteration progress
        progress = min(iteration / max_iterations, 1.0)
        current_radius = initial_radius + (final_radius - initial_radius) * progress

        def constraint_adaptive_sphere(x_flat):
            points_reshaped = x_flat.reshape(self.n_points, self.d)
            norms = np.linalg.norm(points_reshaped, axis=1)
            return norms - current_radius

        return {'type': 'eq', 'fun': constraint_adaptive_sphere}
