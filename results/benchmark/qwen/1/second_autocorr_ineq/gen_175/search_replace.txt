<DESCRIPTION>
Adding FFT-based convolution computation to improve performance for large step functions. This leverages the fact that for large arrays (which the problem allows), FFT-based convolution is much faster than direct computation. The key insight is that autoconvolution f*f can be computed efficiently as ifft(fft(f)^2). This will dramatically speed up the computation of the objective function, allowing more iterations or larger problem sizes within the time constraint.
</DESCRIPTION>

@jit(nopython=True)
def compute_autoconvolution_numba(f_vals):
    """
    Compute autoconvolution g = f*f using efficient Numba implementation
    For small arrays, use direct computation. For large arrays, switch to FFT-based method.
    """
    n = len(f_vals)

    # For very small arrays, use direct computation
    if n <= 100:
        # Convolution result has length 2*n-1
        conv_len = 2 * n - 1
        g = np.zeros(conv_len)

        # Compute convolution manually for efficiency
        for i in range(n):
            for j in range(n):
                idx = i + j
                if 0 <= idx < conv_len:
                    g[idx] += f_vals[i] * f_vals[j]
        return g
    else:
        # For larger arrays, use FFT-based method for efficiency
        # This requires padding to avoid circular convolution effects
        import numpy as np
        from scipy.fft import fft, ifft

        # Zero-pad to avoid circular convolution effects
        padded_length = 2 * n - 1
        f_padded = np.pad(f_vals, (0, padded_length - n), mode='constant', constant_values=0)

        # FFT-based convolution: f*f = ifft(fft(f)^2)
        F = fft(f_padded)
        G_fft = F * F  # Point-wise multiplication in frequency domain
        g = ifft(G_fft).real[:padded_length]

        return g
