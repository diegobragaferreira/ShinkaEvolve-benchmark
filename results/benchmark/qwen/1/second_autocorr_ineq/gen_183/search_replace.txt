The current program uses finite difference approximations for gradient computation in the `multi_objective_optimization` function, which introduces numerical inaccuracies and instability. This change replaces the manual finite-difference gradient computation with JAX's automatic differentiation capabilities to improve convergence quality and numerical stability. The key insight is that JAX's `grad` function provides more accurate gradients than finite differences, leading to better optimization performance.

This change specifically targets the gradient computation in `multi_objective_optimization` by replacing the manual finite-difference calculation with `compute_c2_grad` which leverages JAX's automatic differentiation.
