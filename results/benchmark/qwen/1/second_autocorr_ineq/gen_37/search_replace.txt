<DESCRIPTION>
The main issue with the current implementation is the piecewise linear integration method for computing ||g||₂² which uses a simplified quadratic approximation. By replacing this with a more accurate trapezoidal integration approach that properly accounts for the convolution structure, we can get more precise C₂ calculations. This should help in finding better step function configurations as the objective function becomes more reliable.

@jit(nopython=True)
def compute_c2_numba(g_vals):
    """Compute C2 value using fast Numba implementation"""
    if len(g_vals) == 0:
        return 0.0

    # Compute norms
    g_l2_sq = 0.0
    g_l1 = 0.0
    g_max = 0.0

    # For L2 norm squared using proper trapezoidal integration
    # We integrate g(t)^2 over the domain [-1/2, 1/2]
    # The autoconvolution g has domain [-1/2, 1/2] with 2*n-1 samples
    # So the spacing is STEP_WIDTH = 0.5/(n-1) where n = len(g_vals)
    # For trapezoidal rule: integral ~ h * (y0 + 2*y1 + 2*y2 + ... + yn)/2

    # Actually, let's compute it more carefully for the convolved function
    # The convolution g = f*f will be defined on [-1/2, 1/2] with 2*n-1 points
    # But since we use a different integration method for the full range,
    # let's simply use trapezoidal integration for the L2 norm squared

    h = STEP_WIDTH
    if len(g_vals) >= 2:
        # Trapezoidal rule for L2 norm squared: int g^2 dt ≈ h * (g[0]^2 + 2*sum(g[i]^2) + g[n-1]^2)/2
        g_l2_sq = g_vals[0]*g_vals[0] + g_vals[-1]*g_vals[-1]
        for i in range(1, len(g_vals)-1):
            g_l2_sq += 2 * g_vals[i] * g_vals[i]
        g_l2_sq *= h / 2.0  # Apply trapezoidal rule factor

    # For L1 norm (sum of absolute values)
    for i in range(len(g_vals)):
        g_l1 += abs(g_vals[i])

    # For infinity norm (max absolute value)
    for i in range(len(g_vals)):
        if abs(g_vals[i]) > g_max:
            g_max = abs(g_vals[i])

    # Compute C2
    if g_l1 > 1e-15 and g_max > 1e-15:
        c2 = g_l2_sq / (g_l1 * g_max)
    else:
        c2 = 0.0

    return c2
