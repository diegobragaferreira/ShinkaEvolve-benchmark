<DESCRIPTION>
The current implementation uses Voronoi diagrams for constraint density estimation but doesn't fully leverage Voronoi-based adaptive mutation. The idea is to enhance the mutation operator by making it more sophisticated: instead of just using Voronoi cell areas for scaling mutation rates, we'll make the mutation parameters (step sizes, scale factors) directly dependent on the Voronoi cell area - smaller cells (higher constraint density) should get more careful, smaller mutations while larger cells (lower constraint density) can handle more aggressive changes.

This approach will help the algorithm better navigate the constraint landscape by:
1. Making mutations adaptive to local geometry
2. Increasing precision in dense regions where small changes matter more
3. Being more exploratory in sparse regions where larger changes are safe
4. Improving convergence by reducing unnecessary large jumps in constrained areas
