This edit introduces a more sophisticated adaptive mutation strategy that leverages Voronoi criticality analysis to guide circle modifications. The key insight is to use Voronoi diagrams to identify which circles are most constrained by their neighbors, and then focus mutation efforts on those critical regions. This approach is expected to improve convergence by concentrating on areas where small adjustments will have the largest impact on overall fitness.

The main changes include:
1. Enhancing the Voronoi criticality computation to be more robust
2. Implementing adaptive mutation rates based on computed criticality scores
3. Adding better radius mutation scaling that respects local constraint density
4. Improving the overall structure of the genetic operators to be more informed by geometric constraints

        circles = individual.copy()
        n = len(circles)

        # Generate Voronoi diagram
        points = circles[:, :2]  # x,y coordinates

        try:
            vor = Voronoi(points)

            # Fallback: return uniform criticality if Voronoi fails
            return np.ones(n) * 0.1
