The key insight is to improve the Voronoi-based criticality calculation to better reflect actual constraint density. The current implementation uses inverse distance to nearest circle, which doesn't properly capture how much room each circle actually has. Instead, I'll implement a more sophisticated approach that calculates the minimum distance to the Voronoi diagram edges, which represents the true geometric constraint boundaries. This will make the mutation operator more intelligent about where to focus radius adjustments.

The improvement involves:
1. Better Voronoi criticality calculation that considers actual geometric constraints
2. Enhanced boundary handling that properly penalizes circles near rectangle edges
3. More efficient spatial data structures for collision checking

    def get_voronoi_criticality(individual):
        """Calculate criticality based on Voronoi diagram - how much room each circle has"""
        circles = individual.copy()
        n = len(circles)

        # Generate Voronoi diagram
        points = circles[:, :2]  # x,y coordinates
        try:
            vor = Voronoi(points)
        except:
            # Fallback if Voronoi fails - return uniform criticality
            return np.ones(n) * 0.01

        criticality_scores = np.zeros(n)

        # For each circle, calculate minimum distance to Voronoi edges
        # This represents the actual geometric constraint
        coords = circles[:, :2]
        for i in range(n):
            # Calculate minimum distance to Voronoi vertices (edges of the Voronoi cell)
            min_dist_to_edge = float('inf')

            # Get Voronoi region for this point
            region_idx = vor.point_region[i]
            if region_idx != -1 and region_idx < len(vor.regions):
                region = vor.regions[region_idx]
                if len(region) > 0 and -1 not in region:
                    # Check distance to all Voronoi vertices in this region
                    for vertex_idx in region:
                        if vertex_idx < len(vor.vertices):
                            vertex = vor.vertices[vertex_idx]
                            dist = np.sqrt((coords[i,0] - vertex[0])**2 + (coords[i,1] - vertex[1])**2)
                            min_dist_to_edge = min(min_dist_to_edge, dist)

            # If we couldn't compute Voronoi edge distance, fall back to distance to nearest neighbor
            if min_dist_to_edge == float('inf'):
                # Get distances to all other circles
                distances = np.sqrt(np.sum((coords - coords[i])**2, axis=1))

                distances[i] = float('inf')
                # Minimum distance to any other circle center
