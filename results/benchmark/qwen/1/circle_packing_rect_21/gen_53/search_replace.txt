<DESCRIPTION>
The current implementation uses a dense pairwise distance matrix computation which is O(n²) and becomes very slow as the number of circles increases. This change introduces a spatial indexing approach using KDTree to efficiently detect collisions, reducing the complexity from O(n²) to approximately O(n log n) for collision detection. This will enable faster evaluation of individuals in the evolutionary algorithm and allow more generations to be run within the time constraint.

The key insight is that we don't need to check every pair of circles for overlap - we only need to check nearby circles based on their spatial proximity.

                penalty += 1000000  # Large penalty for boundary violation

        # Check overlap constraints using spatial indexing for efficiency
        if len(circles) > 1:
            # Build KDTree for efficient neighbor search
            centers = circles[:, :2]
            tree = cKDTree(centers)

            # Find neighbors within distance of (r1 + r2) for each circle
            # This is more efficient than checking all pairs
            max_dist = 2 * max_radius  # Upper bound on possible interaction distance
            pairs = tree.query_pairs(max_dist)
