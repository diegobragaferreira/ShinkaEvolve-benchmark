The key insight is to use Voronoi diagrams to identify regions of high constraint density and apply more careful, smaller mutations there, while allowing larger mutations in sparser areas.

This approach will:
1. Improve the accuracy of constraint density estimation using Voronoi diagrams
2. Apply adaptive mutation step sizes based on Voronoi cell characteristics
3. Better handle edge cases and boundary constraints
4. Provide more stable convergence behavior

            shifted_points = points.copy()
            shifted_points[:, 0] = np.clip(shifted_points[:, 0], 0.01, rect_width - 0.01)
            shifted_points[:, 1] = np.clip(shifted_points[:, 1], 0.01, rect_height - 0.01)

            # Compute Voronoi diagram
            vor = Voronoi(shifted_points)

            # Compute area of Voronoi cells and additional geometric features
            areas = []
            min_distances = []

                # Get vertices of Voronoi cell for point i
                region = vor.regions[vor.point_region[i]]

                    vertices = [vor.vertices[j] for j in region if j >= 0]

                        x = vertices_array[:, 0]
                        y = vertices_array[:, 1]
                        area = 0.5 * np.abs(np.dot(x, np.roll(y, 1)) - np.dot(y, np.roll(x, 1)))
                        areas.append(area)

                distances_to_others = []

                    if i != j:
                        dist = np.sqrt(np.sum((shifted_points[i] - shifted_points[j])**2))
                        distances_to_others.append(dist)
