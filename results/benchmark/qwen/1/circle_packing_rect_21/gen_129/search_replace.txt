The key insight is to enhance the mutation operator by incorporating Voronoi-based criticality analysis more effectively. Currently, the mutation adapts based on Voronoi cell areas, but we can make it even smarter by:

1. Creating a more accurate Voronoi-based constraint density metric that considers actual geometric relationships
2. Using this improved metric to guide both mutation intensity and mutation type selection
3. Implementing adaptive radius mutation that scales with local constraint density
4. Enhancing the position mutation to be more targeted in high-density regions

This approach improves upon the current implementation by making the mutation strategy more sophisticated and data-driven, leading to better exploration of promising regions while avoiding overly aggressive changes in constrained areas.

            constraint_densities = np.zeros(len(positions))

            for i in range(len(positions)):
                # Calculate Voronoi cell area (more accurate than simple bounding box)
                region_idx = vor.point_region[i]
                if region_idx < len(vor.regions) and len(vor.regions[region_idx]) > 0:
                    region = vor.regions[region_idx]
                    if -1 not in region:  # Only finite regions
                        vertices = np.array(vor.vertices)[region]
                        if len(vertices) >= 3:  # Need at least 3 vertices for polygon area
                            # Compute area using shoelace formula
                            x = vertices[:, 0]
                            y = vertices[:, 1]
                            area = 0.5 * np.abs(np.dot(x, np.roll(y, 1)) - np.dot(y, np.roll(x, 1)))

                        else:
                            constraint_densities[i] = 1.0  # Default for small regions
                    else:
                        constraint_densities[i] = 1.0  # Default for infinite or empty regions
                else:
                    constraint_densities[i] = 1.0  # Default case
        except Exception:
            constraint_densities = np.ones(len(positions))

        avg_density = np.mean(constraint_densities)
