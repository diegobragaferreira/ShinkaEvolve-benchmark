<DESCRIPTION>
The current spatial hashing implementation uses a fixed cell size based on the minimum rectangle dimension. This approach doesn't adapt to the actual distribution of circles and can be inefficient. By implementing adaptive grid spacing that adjusts based on circle densities and sizes, we can significantly improve the efficiency of overlap detection, especially in regions with varying circle densities.

This change involves modifying the `check_constraints` function to compute dynamic cell sizes based on the actual distribution of circles, which should make the overlap checking much faster and more adaptive to the problem structure.

def check_constraints(circles: np.ndarray, rect_width: float = 1.0, rect_height: float = 1.0) -> bool:
    """Efficiently check if all circles satisfy the constraints with early termination."""
    n = len(circles)

    # Check boundary constraints first
    for i in range(n):
        x, y, r = circles[i]
        if x - r < 0 or x + r > rect_width or y - r < 0 or y + r > rect_height:
            return False

    # Use grid-based spatial hashing for efficient overlap checking
    if n > 1:
        # Create a grid for spatial indexing
        cell_size = np.min([rect_width, rect_height]) * 0.2  # Cell size based on rectangle dimensions

        grid_height = int(np.ceil(rect_height / cell_size))
