The current implementation uses Voronoi criticality for evaluating constraint density but doesn't fully leverage it in the mutation process. This change enhances the mutation operators to use Voronoi-based criticality more effectively by:

1. Implementing a more sophisticated adaptive mutation that considers both Voronoi cell area and local constraint density
2. Adding a Voronoi-based local refinement step that moves circles to better positions based on their Voronoi regions
3. Improving the spatial hashing collision detection for better performance
4. Using more intelligent circle selection during local optimization based on criticality

This approach should help achieve better packing efficiency by making more informed decisions about where and how to mutate circles based on their geometric constraints.

    def get_voronoi_criticality(individual):

            return np.ones(n) * 0.01

            # Use scipy's Voronoi for better reliability

            boundary_margin = 0.01
            boundary_points = [
                [boundary_margin, boundary_margin],
                [1-boundary_margin, boundary_margin],
                [boundary_margin, 1-boundary_margin],
                [1-boundary_margin, 1-boundary-margin],
                [0.5, boundary_margin],
                [0.5, 1-boundary_margin],
                [boundary_margin, 0.5],
                [1-boundary_margin, 0.5]
            ]
            points = np.vstack([points, boundary_points])

            vor = Voronoi(points)

            # Compute Voronoi cell areas for each original circle
            criticality_scores = np.zeros(n)

            for i in range(n):
                # Find the Voronoi region for this circle
                region_idx = np.where(vor.point_region == i)[0]
                if len(region_idx) > 0 and region_idx[0] < len(vor.regions):
                    region = vor.regions[region_idx[0]]
                    if -1 not in region and len(region) >= 3:
                        # Compute area of Voronoi cell using shoelace formula
                        vertices = np.array([vor.vertices[j] for j in region if j >= 0 and j < len(vor.vertices)])
                        if len(vertices) >= 3:
                            x = vertices[:, 0]
                            y = vertices[:, 1]
                            area = 0.5 * np.abs(np.dot(x, np.roll(y, 1)) - np.dot(y, np.roll(x, 1)))
                            # Criticality inversely proportional to cell area (smaller = more constrained)
                            criticality_scores[i] = 1.0 / (area + 1e-10)
                        else:

                    else:
                        criticality_scores[i] = 1.0

                    criticality_scores[i] = 1.0
