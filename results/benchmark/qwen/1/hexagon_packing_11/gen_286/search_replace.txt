<DESCRIPTION>
The current collision detection uses a brute force O(n²) approach which becomes inefficient for larger populations. I'll implement a spatial grid-based collision detection system that reduces complexity from O(n²) to near O(n) by only checking nearby hexagons instead of all pairs. This will significantly speed up the evaluation process, especially in later generations when solutions become more complex.

The key insight is to use a uniform grid where each cell contains a list of hexagons that intersect with that grid cell. When checking for collisions, we only need to check hexagons in the same or adjacent cells rather than all pairs.
</DESCRIPTION>

class SpatialGrid:
    """Spatial grid for efficient collision detection"""

    def __init__(self, grid_size=2.8):
        self.grid_size = grid_size
        self.grid = {}

    def clear(self):
        """Clear the grid"""
        self.grid.clear()

    def add_hexagon(self, hex_id, hex_poly):
        """Add a hexagon to the spatial grid"""
        bbox = hex_poly.bounds
        min_x, min_y, max_x, max_y = bbox

        # Determine grid cells this hexagon occupies
        min_col = int(min_x // self.grid_size)
        max_col = int(max_x // self.grid_size)
        min_row = int(min_y // self.grid_size)
        max_row = int(max_y // self.grid_size)

        for col in range(min_col, max_col + 1):
            for row in range(min_row, max_row + 1):
                if (col, row) not in self.grid:
                    self.grid[(col, row)] = []
                self.grid[(col, row)].append(hex_id)

    def get_neighbors(self, hex_id, hex_poly):
        """Get potential neighbor hexagons that might collide"""
        neighbors = []
        bbox = hex_poly.bounds
        min_x, min_y, max_x, max_y = bbox

        # Determine grid cells this hexagon occupies
        min_col = int(min_x // self.grid_size)
        max_col = int(max_x // self.grid_size)
        min_row = int(min_y // self.grid_size)
        max_row = int(max_y // self.grid_size)

        # Check neighboring cells
        for col in range(min_col - 1, max_col + 2):
            for row in range(min_row - 1, max_row + 2):
                if (col, row) in self.grid:
                    neighbors.extend(self.grid[(col, row)])

        return [h_id for h_id in neighbors if h_id != hex_id]

Optimize the local refinement process by using a more efficient coordinate descent approach. Instead of trying all possible steps for each parameter, we'll use a single step size and only update parameters that actually improve the fitness. This reduces the number of evaluations while maintaining effectiveness in finding better local solutions.

    def local_refinement(self, individual, max_iter=50):

        # Simple gradient-free local search using coordinate descent
        best_individual = individual.copy()
        best_fitness = self.evaluate_individual(best_individual)

    def local_refinement(self, individual, max_iter=50):
        """Apply local refinement to improve individual quality"""
        # More efficient local search using coordinate descent with step size adjustment
        best_individual = individual.copy()
        best_fitness = self.evaluate_individual(best_individual)

        step_size = 0.1
        for _ in range(max_iter):
            improved = False
            # Try small perturbations to each parameter
            for i in range(len(best_individual)):
                for j in range(3):  # x, y, angle
                    original_value = best_individual[i][j]
                    test_individual = best_individual.copy()

                    # Try both positive and negative steps
                    for step in [-step_size, step_size]:
                        if j < 2:  # x or y
                            test_individual[i][j] = original_value + step
                        else:  # angle
                            test_individual[i][j] = (original_value + step) % 360

                        fitness = self.evaluate_individual(test_individual)
                        if fitness > best_fitness:  # Since we maximize, higher fitness is better
                            best_fitness = fitness
                            best_individual = test_individual
                            improved = True
                            break  # Found improvement, move to next parameter

            if not improved:
                # Reduce step size if no improvement was found
                step_size *= 0.5
                if step_size < 1e-6:  # Stop if step size gets too small
                    break

        return best_individual
