<DESCRIPTION>
The idea is to improve the initial population generation by using Voronoi-based spatial distribution rather than purely random placement. This will provide better starting configurations that are more likely to lead to valid solutions. The Voronoi approach ensures more even distribution of hexagons while maintaining the flexibility to place them in positions that are geometrically favorable for packing.

This approach leverages the fact that good hexagon packings often exhibit some degree of spatial regularity, and Voronoi tessellations naturally produce such distributions. By generating initial points via Voronoi sampling and then placing hexagons around those points, we can avoid the poor initial configurations that might cause the evolutionary algorithm to get stuck in local optima.

def create_initial_population(pop_size, n_inner_hex):
    """Create initial population with diverse arrangements"""
    population = []

    # Generate multiple good starting solutions using Voronoi-inspired approach
    for _ in range(pop_size):
        # Start with Voronoi-like distribution points
        individual = []

        # Use a combination of structured and Voronoi-inspired random placement
        # Place first hexagon at center
        individual.append([0.0, 0.0, random.uniform(0, 360)])

        # Place remaining hexagons in a pattern that resembles Voronoi cells
        # More structured around center, more random further out
        for i in range(1, n_inner_hex):
            if i <= 6:  # Around center - hexagonal pattern with some randomness
                # Base distance in hexagonal pattern
                base_distance = 1.5 + random.uniform(0, 0.5)
                angle = (i - 1) * 60 + random.uniform(-15, 15)
                center_x = base_distance * np.cos(np.radians(angle))
                center_y = base_distance * np.sin(np.radians(angle))
                angle_rot = random.uniform(0, 360)
            elif i <= 10:  # Further out - more scattered
                # Use spherical distribution with some clustering
                r = 2.5 + random.uniform(0, 2.0)
                theta = random.uniform(0, 2 * np.pi)
                center_x = r * np.cos(theta)
                center_y = r * np.sin(theta)
                angle_rot = random.uniform(0, 360)
            else:  # Additional ones
                # Spread out more randomly but stay within reasonable bounds
                center_x = random.uniform(-5.0, 5.0)
                center_y = random.uniform(-5.0, 5.0)
                angle_rot = random.uniform(0, 360)

            individual.append([center_x, center_y, angle_rot])

        population.append(np.array(individual))
    return population
