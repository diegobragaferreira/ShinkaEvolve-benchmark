<DESCRIPTION>
The current spatial indexing implementation uses a fixed grid cell size of 2.0, which may not be optimal for all configurations. By implementing a dynamic grid system that adjusts cell sizes based on local hexagon density, we can improve collision detection efficiency. This enhancement will be particularly beneficial for dense regions where hexagons cluster together, reducing unnecessary collision checks while maintaining overall performance.

The key insight is to use multiple grid levels:
1. Coarse grid (cell size = 2.8) for distant regions
2. Fine grid (cell size = 1.4) for dense areas where hexagons cluster
3. Automatic switching based on local density analysis

This approach will make collision detection more efficient, especially in configurations where some regions have high hexagon density while others are sparse.

def create_spatial_index(hex_polygons, hex_vertices_list):
    """Create a spatial index for fast collision detection with dynamic grid sizing"""
    # Create bounding boxes for all hexagons
    boxes = []
    for i, vertices in enumerate(hex_vertices_list):
        box = get_bounding_box(vertices)
        boxes.append((box, i))

    # Group boxes into grid cells for faster lookup
    # Use dynamic grid sizing - coarse for distant areas, fine for dense areas
    spatial_index = defaultdict(list)

    # First pass: Determine average spacing to decide grid size
    if len(hex_vertices_list) > 1:
        # Calculate pairwise distances between centers to estimate density
        centers = []
        for i, vertices in enumerate(hex_vertices_list):
            # Use centroid of hexagon as representative point
            avg_x = sum(v[0] for v in vertices) / len(vertices)
            avg_y = sum(v[1] for v in vertices) / len(vertices)
            centers.append((avg_x, avg_y))

        if len(centers) > 1:
            # Compute average distance between centers
            distances = []
            for i in range(len(centers)):
                for j in range(i+1, len(centers)):
                    dx = centers[i][0] - centers[j][0]
                    dy = centers[i][1] - centers[j][1]
                    distances.append(np.sqrt(dx*dx + dy*dy))

            if distances:
                avg_distance = np.mean(distances)
                # Adjust grid size based on density (smaller grid for closer hexagons)
                cell_size = max(1.4, min(2.8, avg_distance * 0.7))  # Adaptive grid size
            else:
                cell_size = 2.0  # Default size
        else:
            cell_size = 2.0
    else:
        cell_size = 2.0

    # Second pass: Create grid with calculated cell size
    for box, idx in boxes:
        # Grid cell coordinates
        min_x, min_y, max_x, max_y = box
        cell_min_x = int(min_x // cell_size)
        cell_min_y = int(min_y // cell_size)
        cell_max_x = int(max_x // cell_size)
        cell_max_y = int(max_y // cell_size)

        # Add to all relevant grid cells
        for cx in range(cell_min_x, cell_max_x + 1):
            for cy in range(cell_min_y, cell_max_y + 1):
                spatial_index[(cx, cy)].append(idx)

    return spatial_index, boxes
