<DESCRIPTION>
The current implementation uses only one initial configuration and local optimization. To improve the chances of finding a better solution, I'll implement a multi-start optimization approach where we try multiple different initial configurations and run the optimization from each one. This increases the probability of escaping local optima and finding a globally better solution.

The key changes include:
1. Creating several diverse initial configurations
2. Running optimization from each initial configuration
3. Keeping track of the best solution found across all starts
4. Adding systematic perturbation of initial configurations to avoid getting stuck in similar local optima
