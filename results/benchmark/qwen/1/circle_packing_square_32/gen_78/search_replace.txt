<DESCRIPTION>
The current implementation uses a nested loop approach for overlap checking which is inefficient for large numbers of circles. I'll optimize the collision detection by implementing a spatial grid approach that reduces the complexity from O(n²) to approximately O(n) by only checking nearby circles instead of all pairs. This will significantly speed up the validation process while maintaining accuracy.

This change involves:
1. Creating a spatial grid to partition the unit square
2. Only checking collisions between circles in the same or adjacent grid cells
3. Maintaining the existing functionality while improving performance

    def validate_circle_placement(circles):
        """Check if all circles are within bounds and non-overlapping."""
        # Check containment
        positions = circles[:, :2]
        radii = circles[:, 2]

        # Vectorized containment check
        containment_mask = (
            (radii <= positions[:, 0]) &
            (positions[:, 0] <= 1 - radii) &
            (radii <= positions[:, 1]) &
            (positions[:, 1] <= 1 - radii)
        )

        if not np.all(containment_mask):
            return False

        # Optimized overlap checking using spatial grid
        # Create a spatial grid to reduce number of distance calculations
        grid_size = 10  # 10x10 grid
        cell_size = 1.0 / grid_size

        # Create grid mapping: each cell contains indices of circles in that cell
        grid = {}

        # Assign each circle to its grid cell
        for i, (x, y) in enumerate(positions):
            cell_x = int(x // cell_size)
            cell_y = int(y // cell_size)
            if cell_x >= grid_size:
                cell_x = grid_size - 1
            if cell_y >= grid_size:
                cell_y = grid_size - 1
            cell = (cell_x, cell_y)
            if cell not in grid:
                grid[cell] = []
            grid[cell].append(i)

        # Check overlaps only for circles in same or adjacent cells
        for i in range(len(circles)):
            x1, y1 = positions[i]
            r1 = radii[i]

            # Check the cell and all 8 adjacent cells
            cell_x = int(x1 // cell_size)
            cell_y = int(y1 // cell_size)

            for dx in [-1, 0, 1]:
                for dy in [-1, 0, 1]:

                                dy = y1 - y2
