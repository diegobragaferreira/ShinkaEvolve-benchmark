<DESCRIPTION>
This edit enhances the Voronoi initialization by implementing boundary-weighted candidate selection. The key insight is that larger circles can potentially be placed near square boundaries and corners, so we should favor these regions during candidate selection. This builds upon the successful pattern from earlier generations that showed strategic placement accelerates convergence.

The approach modifies the `initialize_with_voronoi` function to:
1. Assign higher probability weights to Voronoi vertices near boundaries (within 0.1 units)
2. Use weighted random sampling to select candidates
3. This helps place larger circles near edges where they can achieve better radii

This is expected to improve the initial quality of solutions and accelerate convergence toward better configurations.

    def initialize_with_voronoi():
        """Initialize circle positions using Voronoi-based approach with boundary weighting"""
        # Generate initial points using a grid-like pattern with some randomness
        n_points = 64  # More points for better Voronoi coverage
        points = []

        # Create a systematic point distribution
        for i in range(8):
            for j in range(8):
                x = 0.1 + i * 0.125 + np.random.uniform(-0.02, 0.02)
                y = 0.1 + j * 0.125 + np.random.uniform(-0.02, 0.02)
                if 0 <= x <= 1 and 0 <= y <= 1:
                    points.append([x, y])

        points = np.array(points)

        # Create Voronoi diagram
        try:
            vor = Voronoi(points)

            # Get Voronoi vertices as candidate centers
            candidates = []
            for vertex in vor.vertices:
                if 0 <= vertex[0] <= 1 and 0 <= vertex[1] <= 1:
                    candidates.append(vertex)

            # If we have enough candidates, sample them with boundary weighting
            if len(candidates) >= 32:
                # Compute weights: higher weight for candidates near boundaries
                weights = []
                for vertex in candidates:
                    x, y = vertex
                    # Distance to nearest boundary
                    dist_to_boundary = min(x, 1-x, y, 1-y)
                    # Weight inversely proportional to distance (but not too extreme)
                    weight = 1.0 + 2.0 * max(0, 0.1 - dist_to_boundary)
                    weights.append(weight)

                # Normalize weights
                weights = np.array(weights)
                weights = weights / np.sum(weights)

                # Sample with weights
                selected_indices = np.random.choice(len(candidates), 32, replace=False, p=weights)
                centers = np.array([candidates[i] for i in selected_indices])
            else:
                # Fall back to sampling original points
                selected_indices = np.random.choice(len(points), 32, replace=False)
                centers = points[selected_indices]

        except:
            # Fallback to simple random initialization
            centers = np.random.rand(32, 2)

        # Initialize with small radii
        circles = np.zeros((32, 3))
        circles[:, 0] = centers[:, 0]
        circles[:, 1] = centers[:, 1]
        circles[:, 2] = 0.02  # Small initial radius

        return circles
