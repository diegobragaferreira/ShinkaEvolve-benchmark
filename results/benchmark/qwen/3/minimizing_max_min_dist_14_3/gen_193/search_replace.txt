This change introduces adaptive constraint handling that dynamically adjusts penalty weights based on constraint violations during optimization, rather than using fixed penalties. This approach helps maintain better balance between constraint satisfaction and objective function optimization throughout the evolutionary process. The adaptive nature allows the optimizer to be more aggressive in exploring the search space initially when constraints are less tight, then become more conservative as solutions approach feasibility.

def adaptive_penalty_objective(x_flat, iteration=0, base_penalty=1e6):
    """Objective function with adaptive penalty for out-of-bounds points.

    Args:
        x_flat: Flattened array of point coordinates [x1, y1, z1, x2, y2, z2, ...]
        iteration: Current iteration number for adaptive scaling
        base_penalty: Base weight for constraint penalty

    Returns:
        Value to minimize (includes penalty for constraint violations)
    """
    # Reshape flat array back to points
    n_points = 14
    points = x_flat.reshape((n_points, 3))

    # Count constraint violations
    violation_count = 0
    total_violation = 0.0

    # Check constraint violations and compute penalty
    penalty = 0
    for i in range(n_points):
        for j in range(3):  # x, y, z coordinates
            if points[i, j] < 0:
                violation_count += 1
                total_violation += abs(points[i, j])
                penalty += base_penalty * (0 - points[i, j])**2
            elif points[i, j] > 1:
                violation_count += 1
                total_violation += abs(points[i, j] - 1)
                penalty += base_penalty * (points[i, j] - 1)**2

    # Adaptive penalty weighting based on violation level
    if violation_count > 0:
        # Scale penalty based on severity of violations
        violation_factor = 1.0 + 0.1 * (total_violation / violation_count)
        penalty *= violation_factor

    # Calculate min/max ratio
    ratio = min_max_ratio(points)

    # Return value to minimize (negative ratio + penalty)
    return -ratio + penalty
