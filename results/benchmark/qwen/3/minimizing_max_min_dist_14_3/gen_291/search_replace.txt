By explicitly constraining points to lie on or near the unit sphere during optimization, we can achieve more reliable convergence and better spatial distribution. This approach leverages the fact that optimal configurations for this problem often exhibit spherical symmetry or near-spherical distributions, so enforcing spherical constraints naturally guides the optimization toward more promising regions of the search space.

The key insight is to modify the objective function to include a spherical constraint term that helps maintain points on or near the unit sphere during optimization, which is particularly important for achieving high min/max distance ratios.

    def objective(x):
        # Reshape x into 14 points in 3D
        points = x.reshape(-1, 3)

        # Calculate pairwise distances
        distances = pdist(points)

        # Handle edge cases
        if len(distances) == 0:
            return -1.0

        # Remove any NaN or infinite values
        distances = distances[np.isfinite(distances)]

        if len(distances) == 0:
            return -1.0

        # Calculate min and max distances
        d_min = np.min(distances)
        d_max = np.max(distances)

        # Return negative ratio to maximize (since we're minimizing)
        if d_max <= 0:
            return -1.0

        # Add spherical constraint component to guide optimization
        # This encourages points to stay near unit sphere which typically improves min/max ratios
        norms = np.linalg.norm(points, axis=1)
        spherical_penalty = np.sum((norms - 1.0)**2) * 1e-3

        return -(d_min / d_max) + spherical_penalty
