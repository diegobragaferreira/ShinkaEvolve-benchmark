The current implementation uses fixed perturbation sizes in local optimization. I'll implement adaptive perturbation sizing that dynamically adjusts based on the optimization landscape and iteration progress to improve convergence speed and solution quality.

The key insight is to make local search more intelligent by:
1. Using a progressive refinement approach where perturbations decrease over time
2. Making larger initial moves for exploration and smaller refined moves for exploitation
3. Implementing a more sophisticated adaptive scheme that considers both iteration progress and recent improvement trends

    def smart_local_optimization(self, individual, max_iter=100):
        """Enhanced local optimization with adaptive perturbation sizing"""
        best_individual = deepcopy(individual)
        best_fitness, _ = self.evaluator.evaluate_fitness(best_individual[:, :2], best_individual[:, 2])

        # Track recent improvements for adaptive perturbation sizing
        recent_improvements = []
        max_recent = 10

        for iteration in range(max_iter):
            # Dynamic perturbation sizing based on iteration progress and recent performance
            progress = iteration / max_iter

            # Progressive perturbation that decreases over time
            base_displacement = 0.3 * (1 - progress * 0.8)  # Starts at 0.3, ends at ~0.06

            # Adjust perturbation based on recent performance
            if len(recent_improvements) > 0:
                avg_improvement = np.mean(recent_improvements[-5:]) if len(recent_improvements) >= 5 else np.mean(recent_improvements)
                # If recent performance was good, make smaller moves to refine
                if avg_improvement > 1e-6:
                    base_displacement *= 0.7
                # If recent performance was poor, make larger moves to escape local minima
                elif avg_improvement < -1e-5:
                    base_displacement *= 1.3

            mutated = deepcopy(best_individual)
            idx = random.randint(0, len(mutated)-1)

            # Perturb position with adaptive displacement
            mutated[idx][0] += random.uniform(-base_displacement, base_displacement)
            mutated[idx][1] += random.uniform(-base_displacement, base_displacement)

            # Perturb rotation with adaptive displacement
            rotation_displacement = 8 * (1 - progress * 0.9)  # Starts at 8, ends at ~0.8
            mutated[idx][2] += random.uniform(-rotation_displacement, rotation_displacement)
