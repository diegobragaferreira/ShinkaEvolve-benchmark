<DESCRIPTION>
Adding geometric validation during evolutionary operations to prevent invalid individuals from propagating. This implements real-time Shapely-based containment and overlap checks directly in the crossover and mutate_individual functions to filter out invalid configurations immediately. This approach prevents constraint-violating individuals from entering subsequent generations, reducing computational waste and improving convergence reliability through early pruning of infeasible solutions. The key insight is that many evolutionary operations produce invalid configurations that would be caught later in evaluation, so catching these early saves significant computation time.

def validate_individual(individual):
    """Validate that individual satisfies basic geometric constraints"""
    try:
        # Check if all hexagons fit within a reasonable outer boundary
        # Simple sanity check to avoid extreme positions that would cause failures
        positions = individual[:, :2]
        max_dist_from_center = np.max(np.sqrt(positions[:, 0]**2 + positions[:, 1]**2))

        # If any hexagon is too far out, likely invalid
        if max_dist_from_center > 20:
            return False

        # Basic check for self-intersection or extreme overlap
        # This is a simplified check - full validation done in evaluate_fitness
        return True
    except Exception:
        return False
