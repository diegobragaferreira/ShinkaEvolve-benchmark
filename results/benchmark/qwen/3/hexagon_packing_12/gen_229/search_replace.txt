<DESCRIPTION>
The current implementation uses differential evolution but doesn't leverage the inherent symmetry properties of hexagon packing problems. By implementing symmetry-aware optimization with multiple initial configurations and rotational degrees of freedom, we can explore better solutions. The key insight is that hexagon packings often benefit from rotational symmetry, and we should optimize both positions and orientations simultaneously rather than fixing all rotations to zero.

This change introduces:
1. Multiple symmetric initial configurations to increase exploration
2. Full optimization of both positions and rotations (not just positions)
3. A more intelligent multi-start approach using known good symmetric patterns
4. Better handling of rotational degrees of freedom that can significantly improve packing density

def optimize_positions(initial_config):
    """Optimize positions using differential evolution for better global search"""
    packer = HexagonPacker()

    def objective(params):
        # Reshape parameters back to hex_data format (positions only)
        hex_data = initial_config.copy()
        idx = 0
        for i in range(len(hex_data)):
            hex_data[i][0] = params[idx]
            hex_data[i][1] = params[idx + 1]
            idx += 2

        # Calculate outer radius for this configuration
        outer_radius = packer.calculate_max_distance_from_center(hex_data)

        # Evaluate configuration
        validity, inv_radius = packer.evaluate_configuration(hex_data, outer_radius)

        if not validity:
            return 1e10  # Large penalty for invalid configurations
        return -inv_radius  # Negative because we maximize

    # Flatten initial configuration
    initial_params = []
    for i in range(len(initial_config)):
        initial_params.extend([initial_config[i][0], initial_config[i][1]])

    # Bounds for positions: [-5, 5] for each coordinate
    bounds = [(-5, 5), (-5, 5)] * len(initial_config)

    # Use differential evolution for global optimization
    result = differential_evolution(
        objective,
        bounds,
        maxiter=100,
        popsize=15,
        tol=1e-6,
        mutation=(0.5, 1),
        recombination=0.7,
        seed=42
    )

    # Reconstruct optimized configuration
    optimized_config = initial_config.copy()
    idx = 0
    for i in range(len(optimized_config)):
        optimized_config[i][0] = result.x[idx]
        optimized_config[i][1] = result.x[idx + 1]
        idx += 2

    return optimized_config

def optimize_positions_and_orientations(initial_config):

        hex_data = initial_config.copy()
        idx = 0
