<DESCRIPTION>
Adding symmetry-aware optimization by implementing a custom mutation operator that preserves the symmetric structure of hexagon packings during evolutionary optimization. This approach will help maintain beneficial symmetries that are known to produce high-quality solutions while avoiding local minima traps. The key insight is that hexagon packings often benefit from symmetric arrangements, so we should design optimization operators that respect and enhance these symmetries rather than breaking them randomly.

The main changes include:
1. Adding a symmetry-aware mutation function that maintains rotational and reflective symmetries
2. Implementing a more sophisticated multi-start approach that generates diverse symmetric configurations
3. Adding a rotation refinement step that specifically targets improving rotational arrangements

    return configs

def symmetry_aware_mutation(params, mutation_strength=0.1):
    """Apply symmetry-aware mutation that respects hexagonal symmetry properties"""
    mutated_params = params.copy()

    # For hexagonal arrangements, we should preserve some symmetry patterns
    # Group hexagons into symmetric pairs/groups

    # Mutate positions with some consideration for symmetry
    for i in range(0, len(mutated_params), 3):  # Process each hexagon
        # Mutate x coordinate
        mutated_params[i] += np.random.normal(0, mutation_strength)
        # Mutate y coordinate
        mutated_params[i+1] += np.random.normal(0, mutation_strength)
        # Mutate angle (but keep within reasonable range)
        mutated_params[i+2] += np.random.normal(0, mutation_strength * 2)
        mutated_params[i+2] = mutated_params[i+2] % 360  # Keep angle in [0,360)

    # Apply symmetry constraint: enforce that opposite positions remain symmetric
    # This maintains the hexagonal symmetry structure
    for i in range(0, 12, 2):  # Process pairs of opposite hexagons
        idx1 = i
        idx2 = (i + 6) % 12  # Opposite hexagon

        if idx1 < 6 and idx2 >= 6:
            # Maintain symmetry: opposite hexagons should be mirror images
            x1, y1 = mutated_params[idx1*3], mutated_params[idx1*3 + 1]
            x2, y2 = mutated_params[idx2*3], mutated_params[idx2*3 + 1]

            # Force symmetry: y-coordinates should be negated, x-coordinates same magnitude
            mutated_params[idx2*3] = -x1  # Mirror x
            mutated_params[idx2*3 + 1] = -y1  # Mirror y

    return mutated_params
