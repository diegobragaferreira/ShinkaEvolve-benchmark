<DESCRIPTION>
The key insight is to implement a more sophisticated symmetry-aware mutation that uses exponential decay for mutation strength rather than linear decay, and to add a new adaptive temperature scheduling mechanism. This addresses the limitations in the current implementation where mutation strength decays linearly and lacks dynamic temperature adaptation during simulated annealing.

The changes involve:
1. Modifying the `mutate_symmetrically` method to use exponential decay for mutation strength (following successful patterns from previous generations)
2. Adding adaptive temperature scheduling in the optimization process
3. Refining the symmetry-aware mutation to better maintain rotational symmetries while enabling effective exploration

    def optimize_stage(self, initial_config: np.ndarray, stage: int, max_generations: int = 50) -> Tuple[np.ndarray, float]:
        """Single stage optimization with specific mutation strategy and adaptive temperature control"""
        # Stage 1: Population initialization with stochastic perturbations
        population_size = 25 if stage <= 2 else 15  # Fewer individuals in final stage

        # Start with best configuration and add perturbations
        population = [initial_config.copy()]
        for _ in range(population_size - 1):
            variant = initial_config.copy()
            # Add small random perturbations to positions
            for i in range(len(variant)):
                variant[i][0] += random.gauss(0, 0.1) if random.random() < 0.5 else 0
                variant[i][1] += random.gauss(0, 0.1) if random.random() < 0.5 else 0
            population.append(variant)

        for gen in range(max_generations):
            # Check timeout
            if time.time() - self.start_time > self.timeout * 0.8:
                break

            # Adaptive temperature scheduling
            # Dynamic cooling based on progress to improve convergence behavior
            base_temperature = 0.8
            cooling_factor = 0.95
            temperature = base_temperature * (cooling_factor ** gen)

            # Evaluate fitness of entire population
            fitness_scores = []
            for individual in population:
                score = HexagonPackingEvaluator.evaluate_configuration(individual)
                fitness_scores.append(score)

            # Select top performers (elitism)

            elite_count = population_size // 3
            elite = [population[i].copy() for i in sorted_indices[:elite_count]]

            # Generate new population through mutation with acceptance criterion
            new_population = elite.copy()

            # Fill remaining slots through mutation with probabilistic acceptance based on temperature
            while len(new_population) < population_size:
                parent = random.choice(elite)
                mutated = SymmetryAwareMutation.mutate_symmetrically(
                    parent,
                    mutation_strength=0.2,
                    stage=stage,
                    generation=gen,
                    max_generations=max_generations

                mutated_score = HexagonPackingEvaluator.evaluate_configuration(mutated)
                parent_score = HexagonPackingEvaluator.evaluate_configuration(parent)
