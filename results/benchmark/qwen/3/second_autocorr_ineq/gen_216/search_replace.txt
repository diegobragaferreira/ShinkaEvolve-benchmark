By implementing multi-scale Gaussian pattern construction, we can create more sophisticated initial functions that have better autoconvolution properties. This approach leverages mathematical insights about how structured patterns in the original function translate to desirable properties in the autoconvolution.

The key improvements:
1. Replace simple alternating pattern with multi-scale Gaussian bumps
2. Each bump has randomized position, width, and height to increase diversity
3. Add more structured noise to avoid premature convergence
4. This should help create functions that produce flatter autoconvolution profiles, improving the C2 ratio

def generate_initial_population(pop_size, min_length=500, max_length=2000):
    """Generate initial population with multi-scale Gaussian pattern initialization."""
    population = []
    for _ in range(pop_size):
        # Random length within range
        length = np.random.randint(min_length, max_length + 1)

        # Multi-scale Gaussian pattern initialization
        individual = np.zeros(length)

        # Add several Gaussian bumps at different positions and scales
        # This creates more structured and mathematically motivated patterns
        num_bumps = min(15, length // 10)  # Dynamically adjust number of bumps
        for _ in range(num_bumps):
            # Random center position
            center = np.random.randint(0, length)
            # Random width (scale) - smaller for more detailed structures
            width = np.random.randint(1, max(3, length // 20))
            # Random height
            height = np.random.uniform(0.5, 1.5)

            # Fill in the Gaussian shape
            for i in range(length):
                distance = abs(i - center)
                if distance < width * 3:  # Only fill within reasonable range
                    gaussian_val = height * np.exp(-0.5 * (distance / width)**2)
                    individual[i] += gaussian_val

        # Apply structured noise to avoid perfect symmetry and increase diversity
        for i in range(length):
            if np.random.random() < 0.3:  # 30% chance to modify
                individual[i] = max(0.0, individual[i] + np.random.normal(0, 0.1))

        # Convert back to list
        population.append(individual.tolist())

    return population
