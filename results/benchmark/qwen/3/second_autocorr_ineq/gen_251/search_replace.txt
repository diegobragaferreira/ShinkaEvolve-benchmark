<DESCRIPTION>
The main idea is to improve the convolution computation by replacing the current direct convolution implementation with a more efficient FFT-based approach that maintains accuracy while reducing computational complexity. The current implementation uses O(n²) direct convolution which becomes inefficient for large step functions. The proposed change implements FFT-based convolution which is O(n log n) and should scale much better.

This change focuses on the `compute_autoconvolution_numba` function to switch from direct convolution to FFT-based convolution while maintaining the same interface and behavior. This should significantly speed up the computation for larger step functions and enable better exploration of the search space within the time constraint.
