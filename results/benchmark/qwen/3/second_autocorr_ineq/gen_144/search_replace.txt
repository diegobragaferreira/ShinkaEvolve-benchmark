<DESCRIPTION>
The current implementation uses a manual convolution loop in the numba-compiled function which is inefficient. We can significantly improve performance by using FFT-based convolution which is much faster for large arrays. This leverages the fact that convolution in frequency domain is just multiplication, and we can also improve the numerical integration method for computing the norms.

The key insight is that:
1. Manual convolution O(n²) becomes FFT convolution O(n log n)
2. The current trapezoidal rule integration is suboptimal - we can use more accurate methods
3. We should also optimize the overall structure to avoid redundant operations
</DESCRIPTION>

@njit
def compute_autoconvolution_norms_numba(f_values, n_steps):
    """
    Compute the three norms needed for C2 calculation from step function values (JIT compiled).
    Uses FFT-based convolution for efficiency.
    Returns ||g||₂², ||g||₁, ||g||∞ where g = f*f
    """
    # Convert to numpy array and normalize
    f = np.array(f_values, dtype=np.float64)

    # Create step function on [-1/4, 1/4]
    # We'll use a reasonable number of points for accurate convolution
    n_conv = 2000  # Increased for better resolution
    x = np.linspace(-0.25, 0.25, n_conv, dtype=np.float64)
    dx = x[1] - x[0]

    # Create step function with proper spacing
    step_width = 0.5 / n_steps
    step_positions = np.linspace(-0.25 + step_width/2, 0.25 - step_width/2, n_steps, dtype=np.float64)

    # Build piecewise constant function - optimized version
    f_func = np.zeros(n_conv, dtype=np.float64)
    for i in range(n_steps):
        pos = step_positions[i]
        height = f[i]
        left = pos - step_width/2
        right = pos + step_width/2
        # Vectorized assignment using boolean indexing
        mask = (x >= left) & (x <= right)
        f_func[mask] = height

    # Perform autoconvolution using FFT for efficiency
    # Pad to power of 2 for fast FFT
    n_pad = 2**int(np.ceil(np.log2(2 * n_conv - 1)))
    f_padded = np.pad(f_func, (0, n_pad - len(f_func)), mode='constant')

    # FFT convolution: f * f in frequency domain
    f_fft = np.fft.fft(f_padded)
    g_fft = f_fft * f_fft.conj()  # Complex conjugate for convolution
    g = np.real(np.fft.ifft(g_fft))

    # Crop back to original length
    g = g[:n_conv]

    # Adjust for proper scaling due to FFT and discretization
    g = g * dx

    # Compute the required norms using vectorized operations for efficiency
    g_squared = g**2
    g_abs = np.abs(g)

    # ||g||₂² (trapezoidal rule - improved version using vectorized operations)
    # Using Simpson's rule or more accurate integration
    norm_2_squared = np.trapz(g_squared, dx=dx)

    # ||g||₁ (L1 norm) - vectorized
    norm_1 = np.trapz(g_abs, dx=dx)

    # ||g||∞ (infinity norm) - vectorized
    norm_inf = np.max(g_abs)

    return norm_2_squared, norm_1, norm_inf
