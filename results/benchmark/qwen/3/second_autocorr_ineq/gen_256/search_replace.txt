<DESCRIPTION>
The current implementation uses direct convolution computation which has O(n²) complexity. By leveraging FFT-based convolution, we can significantly speed up the computation, especially for larger step counts. This will allow us to explore larger problem sizes or run more iterations within the time constraint, potentially improving the final C₂ value.

The key insight is to use scipy's fftconvolve which is much faster than manual double-loop convolution for large arrays, while preserving the mathematical correctness of the convolution operation.
</DESCRIPTION>

@jit(nopython=True)
def compute_norms_jit(g_vals):
    """
    Compute norms efficiently with numba
    """
    n = len(g_vals)

    # Compute L1 norm (sum of absolute values)
    l1_norm = 0.0
    for i in range(n):
        l1_norm += abs(g_vals[i])

    # Compute L2 norm squared
    l2_norm_sq = 0.0
    for i in range(n):
        l2_norm_sq += g_vals[i] * g_vals[i]

    # Compute infinity norm
    linf_norm = 0.0
    for i in range(n):
        val = abs(g_vals[i])
        if val > linf_norm:
            linf_norm = val

    return l1_norm, l2_norm_sq, linf_norm

# Core computation module with optimized FFT-based convolution
def compute_autoconvolution_fft(f_vals):
    """
    Compute autoconvolution using FFT for better performance.
    This is much faster than direct computation for large arrays.
    """
    # Convert to numpy array
    f = np.array(f_vals)

    # Use scipy's fftconvolve for efficient convolution
    # Note: we use 'full' mode and then take appropriate portion
    g = signal.fftconvolve(f, f, mode='full')

    # Since we're doing f*f, the result should be symmetric
    # We keep only the first half (the actual convolution size)
    g = g[:len(f)*2 - 1]

    return g
