By implementing a more robust handling of FFT convolution with proper padding and numerical checks, we can reduce the likelihood of incorrect convolution results that could lead to suboptimal sequences being selected during optimization. Additionally, we'll add safeguards against extreme values that could skew the C1 calculation.

This improvement targets reducing numerical noise and improving the reliability of the convolution operation, which directly affects the quality of the optimization process and ultimately contributes to achieving a better upper bound for C₁.

    Compute C₁ for a given sequence using FFT for efficiency.
    C₁ = 2n * max(convolution) / (sum(sequence))^2
    """
    n = len(sequence)
    if n == 0:
        return float('inf')

    # Compute convolution using FFT for efficiency with enhanced numerical stability
    try:
        # Pad sequence to avoid wraparound effects and ensure sufficient length for FFT
        padded_length = 2 * n - 1
        if padded_length < 1024:
            # For small sequences, pad to next power of 2 for efficient FFT
            padded_length = 1 << (padded_length - 1).bit_length()
        else:
            # For larger sequences, pad to a multiple of 1024 to maintain FFT efficiency
            padded_length = ((padded_length // 1024) + 1) * 1024

        # Pad the sequence
        padded_seq = np.pad(sequence, (0, padded_length - n), 'constant')

        # Perform FFT-based convolution
        fft_seq = fft(padded_seq)
        conv_fft = fft_seq * np.conj(fft_seq)
        conv = ifft(conv_fft).real[:2*n-1]

        # Check for NaN or Inf values that may result from numerical errors
        if np.any(np.isnan(conv)) or np.any(np.isinf(conv)):
            # Fallback to direct convolution to ensure correctness
            conv = np.convolve(sequence, sequence, mode='full')[:2*n-1]

        max_conv = np.max(conv)

        # Filter out outliers beyond 3 standard deviations
